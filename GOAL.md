# Цель первого выпуска Полки

Дать человеку полезный результат за один короткий путь: **свой файл или HTML-отчёт из примера → личная полка/папка → быстрый просмотр → постоянная ссылка другому человеку → повторное открытие.** Агент и корпоративная установка не обязательны для первой личной работы. Компания может сразу выбрать внутреннюю установку, если её данные нельзя размещать снаружи.

## Решение о реализации

Новый репозиторий и самостоятельные frontend, API, схема данных и запуск. Не импортировать старые editor/bootstrap/DeckDoc/Scene и всю историю миграций Lanka. Отбирать узкие библиотеки, ресурсы и проверенные инварианты после проверки зависимостей; повторять conformance tests. Старое приложение и его данные сохраняются отдельно, без двойной записи в общие таблицы.

## Ближайшие результаты

1. M0: независимая сборка/сервер, identity/tenant/workspace, object store и контракт разрешений. Проверить дешёвый обычный просмотр отдельно от исполнения произвольного HTML.
2. M1: надёжная загрузка, полка/папки, неизменяемая версия, короткая ссылка и отзыв; сохранение переживает перезапуск. Для формата с ещё неготовым preview показать состояние и доступные действия.
3. M2: качественный отчёт, свои данные и прямые поддержанные правки, правильный HTML-viewer, mobile/keyboard, повторная работа.
4. До внешнего выпуска M1+M2: независимые аккаунты, закрытые источники, лимиты, восстановление, реальные адреса и измеренная скорость на целевой сети. Не запускать рекламу на план или статичный макет.

M3: реальный агент и обсуждение/предложения. M4: выбранный корпоративный пилот с SSO, политиками, ролями и выводом сотрудника из компании. M5: расширение по данным использования. Точные задачи P01–P24 — в [плане](docs/DELIVERY_PLAN.md).

## Не потерять при упрощении

Tenant — граница организации; workspace и папки организуют работу внутри. Данные компании не принадлежат исключительно учётной записи уволившегося автора. Сохранение, просмотр, публикация ссылки и официальное утверждение — разные действия. Права и классификация проверяются сервером, включая кеши, агента и ссылки. Обычное чтение файла не запускает агента или отдельный Chromium.

Не включать в первый выпуск полную замену Office, desktop sync client, универсальный Figma-редактор любого DOM/canvas, все агенты/провайдеры, DLP всех форматов, полноценную соцсеть или обещание тысяч интерактивных сессий без замеров.

В прежней задаче такая карточка была заблокирована незавершённой целью Lanka; считать её выполненной ради замены нельзя.
