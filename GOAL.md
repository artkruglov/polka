# Цель первого выпуска Полки

Дать человеку полезный результат за один короткий путь: **артефакт из Claude, GPT, локального или корпоративного агента → собственный snapshot Полки → быстрый просмотр в России и любом разрешённом контуре → публичная витрина или закрытая ссылка с доступом.** Полка не требует встроенного чата и не заменяет агента. Ручной файл остаётся запасным входом. Работа по умолчанию закрыта; агент сохраняет её одной командой и не получает права публикации. Импорт по ссылке и MCP-capture описаны в [контракте быстрых входов](docs/AGENT_CAPTURE_AND_IMPORT.md).

## Решение о реализации

Переход от проверяемого интерфейса к приложению описан в [PROTOTYPE_TO_PRODUCT](docs/PROTOTYPE_TO_PRODUCT.md): принятые токены/сценарии → React UI и договор API → реальное хранение/доступ → воспроизводимая поставка. Demo-модель не превращается в серверную авторизацию. Hosted и self-hosted остаются одним продуктом.

Новый репозиторий и самостоятельные frontend, API, схема данных и запуск. Не импортировать старые editor/bootstrap/DeckDoc/Scene и всю историю миграций Lanka. Отбирать узкие библиотеки, ресурсы и проверенные инварианты после проверки зависимостей; повторять conformance tests. Старое приложение и его данные сохраняются отдельно, без двойной записи в общие таблицы.

## Ближайшие результаты

1. M0: независимая сборка/сервер, identity/tenant/workspace, object store и контракт разрешений. Проверить дешёвый обычный просмотр отдельно от исполнения произвольного HTML.
2. M1: ограниченная надёжная загрузка, полка/папки, неизменяемые версии, живая/закреплённая ссылка и отзыв. Сначала «Только я / По ссылке», затем отдельная приёмка «Приглашённые» перед обещанием закрытого обмена. Сохранение переживает перезапуск; доступ и запрет индексации проверяются на всех путях.
3. M2: качественный отчёт, свои данные и прямые поддержанные правки, правильный HTML-viewer, mobile/keyboard, повторная работа.
4. До первого внешнего выпуска M1: принят поддержанный HTML-viewer, независимые аккаунты, закрытые источники, лимиты, восстановление, реальные адреса, noindex/боты/отзыв и измеренная скорость на целевой сети. M2 не блокирует этот ограниченный выпуск. Сам M1 без M1.2 — только технический storage alpha: его нельзя позиционировать как продукт для артефактов агентов.
5. M1.2 — обязательный activation gate: две простые точки входа для артефактов агентов — `artifact.capture` через MCP и безопасный импорт поддержанной публичной ссылки. Полка сохраняет private snapshot и provenance; ручная загрузка остаётся рабочим fallback. Только после этого можно звать первый внешний пилот как agent-first продукт.

M3: необязательные предложения правок от внешнего агента через MCP, без встроенного чата. M4: выбранный корпоративный пилот с SSO, политиками, ролями и выводом сотрудника из компании. M5: расширение по данным использования. Точные задачи P01–P26 — в [плане](docs/DELIVERY_PLAN.md).

Сначала подключение внешнего агента через MCP или импорт его shared URL и собственная приватная ссылка владельцу; встроенный чат, зеркалирование истории и запуск модели из Полки не являются предпосылками. Компания с запретом внешнего хранения выбирает внутренний пилот после его соответствующего допуска; ранняя установка без SSO/политик не называется корпоративно готовой. [Режимы доступа, поиск и ссылки](docs/SHARING_AND_DISCOVERY.md) и [быстрые входы](docs/AGENT_CAPTURE_AND_IMPORT.md) определяют обязательные проверки.

## Витрина и быстрый первый результат

[Шесть сильных живых демо](docs/DEMO_LIBRARY.md) входят в первое внешнее знакомство с продуктом: открыть и попробовать без аккаунта/агента. M1.1 добавляет [собственные исследования и проекты после небольшого отбора](docs/COMMUNITY_PUBLICATION.md), закладки и лайки. M2 — копию и адаптацию; M4 — библиотеку команды; M5 — подписки, обсуждение и рекомендации. Авторскую витрину не откладывать до полной социальной ленты. Удержание проверяем по возвращениям к полезным работам и обновлениям, не объявляем результатом наличия лайков.

## Не потерять при упрощении

Tenant — граница организации; workspace и папки организуют работу внутри. Данные компании не принадлежат исключительно учётной записи уволившегося автора. Сохранение, просмотр, публикация ссылки и официальное утверждение — разные действия. Права и классификация проверяются сервером, включая кеши, агента и ссылки. Обычное чтение файла не запускает агента или отдельный Chromium.

Не включать в первый выпуск встроенный чат/зеркалирование внешних чатов, полную замену Office, desktop sync client, универсальный Figma-редактор любого DOM/canvas, все агенты/провайдеры, DLP всех форматов, полноценную соцсеть или обещание тысяч интерактивных сессий без замеров.

[Результат и следующий срез](docs/LIVE_SLICE_2026-09-13.md). M0/M1 целиком открыты: впереди HTML-viewer, полная файловая организация, identity onboarding, эксплуатационный допуск и реальная пользовательская приёмка. Этот файл не создаёт и не возобновляет автоматическую цель Codex. В прежней задаче такая карточка была заблокирована незавершённой целью Lanka; считать её выполненной ради замены нельзя.
