# Активная цель: целостный интерфейс и импорт артефактов

21.09.2026: создана новая цель по просьбе пользователя. Предыдущие визуальные пакеты — итерации, не завершённая пользовательская приёмка.

План и критерии: [IMPLEMENTATION_GOAL](docs/IMPLEMENTATION_GOAL.md).

Главный сценарий: передать поддерживаемую публичную ссылку через интерфейс или MCP, получить сохранённый артефакт, открыть его на Полке и осознанно поделиться. Простая закладка и распознавание URL не закрывают этот сценарий.

Начато: единая навигация, shared API/UI/styles, account entity, автоматическая проверка направлений зависимостей новых слоёв. URL import пока не реализован; MCP capture принимает содержимое файлов.
