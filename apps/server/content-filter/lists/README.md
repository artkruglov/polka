# Списки фильтра содержимого

Правила фильтра запрещённого содержимого ([docs/specs/CONTENT_FILTER.md](../../../../docs/specs/CONTENT_FILTER.md)). Файлы читаются при старте приложения и воркера классификатора. Ошибка в строке — ошибка запуска и тестов, а не молча пропущенный термин.

## Файлы

| Файл | Что |
|---|---|
| `csam.txt`, `extremism_terror.txt`, `drugs.txt`, `weapons_explosives.txt`, `doxxing.txt`, `porn.txt`, `suicide.txt`, `gambling.txt`, `piracy.txt`, `vpn.txt` | термины категорий |
| `domains.txt` | домены: `домен [категория]`, по умолчанию `blocklisted_domain`; поддомены совпадают, `.onion` ловится кодом |
| `disposable_email.txt` | одноразовые почтовые сервисы, с которых нельзя зарегистрироваться |
| `known_scripts.txt` | sha256 известных библиотечных скриптов: модель-ревьюер их не читает |

## Формат файла категории

```
# комментарий
@threshold 6          # счёт, с которого категория «флаг»
@high 10              # «высокий» счёт
@block 12             # только csam: блокировка без проверки
@pair substance sale 8 4   # группа, группа, окно в словах, вес пары

0 героин* | substance      # вес 0: только в паре
0 купить | sale
6 кладмен*                 # сам по себе
4 обход блокировок роскомнадзора   # фраза до 4 слов
```

- `слово` — точное слово; `основа*` — любое слово, начинающееся так (не короче 4 букв).
- Регистр, «ё», диакритика, латинские двойники кириллицы и цифры внутри слов нормализуются одинаково для списка и текста: пишите обычными буквами.
- Дефис и точка делят слова: «альфа-пвп» пишется как `альфа пвп`.
- Счёт категории — сумма весов разных найденных терминов плюс пары. Пара считается один раз на каждое разное слово второй группы (намерения): «мефедрон купить, доставка, закладки» — три пары, пять названий веществ рядом с одним «купить» — одна.
- `| группа` — латиница в нижнем регистре; группа должна участвовать в `@pair`.

## Как обновлять

1. **Сначала пример.** Добавьте в `tests/content-filter.test.ts` текст, который фильтр пропустил или поймал зря: в `VIOLATIONS` или в `HONEST`.
2. **Точность важнее полноты.** Слово, которое пишут в новостях, медицине, истории или профилактике, должно весить 0 и работать только в паре с намерением. Новый термин с весом не ниже порога проверьте на тестовых честных текстах.
3. **Экстремизм и терроризм.** Названия организаций берите из официальных перечней (ФСБ — террористические, Минюст — экстремистские). Название само по себе не весит ничего: только рядом с восхвалением или призывом вступить. Удалённые из перечня организации удаляйте и отсюда.
4. **Домены.** Перед добавлением проверьте адрес в реестре Роскомнадзора (blocklist.rkn.gov.ru). Легальные букмекеры (участники ЦУПИС) не добавляются.
5. **Проверка:** `npm test -- tests/content-filter.test.ts`; затем полный `npm run verify`.
6. **Выкатка.** Списки — часть кода: изменения попадают в прод с обычным релизом. Уже сохранённые версии не пересчитываются; решение по ним принимается при следующей ссылке или после ответа модели.

## Что не делать

- Не добавляйте в списки текст пользователей и персональные данные: термины хранятся в журнале модерации и письмах оператору.
- Не добавляйте «пограничные» термины с весом ради полноты: модель прочтёт смысл, а ложная блокировка честного автора дороже пропуска, который поймают жалобы.
