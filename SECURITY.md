# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте приватное сообщение через GitHub:
**Security → Report a vulnerability** в [artkruglov/polka](https://github.com/artkruglov/polka/security/advisories/new).

Опишите затронутую версию или commit, шаги воспроизведения и возможный ущерб. Мы подтвердим получение в течение 5 рабочих дней и сообщим план исправления. Просим не раскрывать детали публично до выпуска исправления.

## Поддерживаемые версии

Проект находится в стадии prerelease (`0.x`). Исправления безопасности выпускаются только для последнего prerelease и ветки `main`.

## Границы модели угроз

- Пользовательский HTML по умолчанию отдаётся статично. Интерактивный режим (`HTML_LIVE_ENABLED`) — экспериментальный и требует отдельного origin для viewer; не включайте его на общем домене приложения.
- Импорт по ссылке (`URL_IMPORT_ENABLED`) выключен по умолчанию.
- Удаление аккаунта (`ACCOUNT_DELETION_ENABLED`) не принято для облачной поставки.
- Скачанные получателем копии не отзываются.

Подробности — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и [docs/HOSTED_VIEWER_DELTA.md](docs/HOSTED_VIEWER_DELTA.md).
