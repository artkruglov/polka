# Поддержка / Support

Можно писать по-русски или по-английски. *Russian or English is fine.*

| Что нужно | Куда |
|---|---|
| Как пользоваться, лимиты, почему не работает сеть в странице, ссылки Claude/ChatGPT | [FAQ](docs/faq.md), [подключение агентов](docs/connect-agents.md) |
| Что уже работает, а что нет | [docs/status.md](docs/status.md), [дорожная карта](docs/roadmap.md) |
| Ошибка: что-то работает не так, как описано | [Issue «Ошибка»](https://github.com/artkruglov/polka/issues/new?template=bug.yml) |
| Идея или недостающая возможность | [Issue «Предложение»](https://github.com/artkruglov/polka/issues/new?template=feature.yml) |
| Уязвимость | Только приватно, см. [SECURITY.md](SECURITY.md) |
| Аккаунт и данные на polochka.app | privacy@polochka.app ([политика](docs/legal/privacy.md), [соглашение](docs/legal/terms.md)) |
| Жалоба на материал по ссылке | Кнопка «Пожаловаться» на странице ссылки или privacy@polochka.app |
| Коммерческая лицензия, своя установка с поддержкой | hello@polochka.app, [COMMERCIAL.md](COMMERCIAL.md), [«Для компаний»](https://polochka.app/enterprise) |

Не прикладывайте к issue токены, cookies, содержимое `.env`, ссылки `/s#…` и приватные материалы.

*English: read the [FAQ](docs/faq.md) and [status](docs/status.md) first; file bugs and ideas as GitHub issues; report vulnerabilities privately per [SECURITY.md](SECURITY.md); for your polochka.app account and data, write to privacy@polochka.app; report a shared page with its «Пожаловаться» (Report) button or by e-mail to privacy@polochka.app; for a commercial license, write to hello@polochka.app. Never attach tokens, cookies, `.env` contents, `/s#…` links or private material to an issue.*

Полка — проект одного мейнтейнера в стадии prerelease: ответ может занять несколько дней. Сроков ответа по договору нет, кроме [коммерческой лицензии](COMMERCIAL.md).
