## Проверки

- `npm test` запускает интеграционные тесты на временных PostgreSQL и S3, `npm test -- --live` — наборы с включённым viewer. CI повторяет это на каждом pull request и дополнительно проверяет лицензии зависимостей, секреты в истории и собранный Docker-образ.
- Быстрый запуск из [README](../README.md) проверен 22.09.2026 на чистом клоне: `npm ci` → `local:setup` → `infra:up` → `db:migrate` → `storage:bootstrap-local` → `account:create` → `build` → `dev`. После этого сработали `/api/health`, главная страница и вход созданным аккаунтом.
