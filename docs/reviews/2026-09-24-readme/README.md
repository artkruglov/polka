## Что сделали

- **Шапка:** логотип `docs/assets/logo.svg` / `logo-dark.svg` (знак `apps/web/icons/mark.svg` и слово «полка» кривыми из IBM Plex Sans SemiBold с трекингом −0,055em, как в интерфейсе; шрифт не нужен), девиз с главной «Сделали с агентом — покажите другим», одна фраза о продукте, ссылки, шесть бейджей shields.io (лицензия, коммерческая лицензия, последний тег, prerelease, MCP, llms.txt).
- **Скриншоты** (`docs/screenshots/`, 1440 px, PNG 95–175 КБ): главная, получатель ссылки (материал Редакции «Контраст в руках» из «Интересного»), «Агенты», «Интересное», «Для компаний». Снимаются `node scripts/render-readme-assets.mjs shot <url> <файл>`; «Агенты» — на локальной установке с тестовым аккаунтом (`POLKA_SESSION`) и адресом polochka.app в тексте (`SHOW_ORIGIN`), как его показывает hosted-страница. Снимок обрезан до блока «Одной фразой»: ниже, пока у аккаунта нет токена, команда Codex показывается как `codex mcp add polka --url ''` (адрес берётся из созданного токена) — это стоит исправить в интерфейсе.
- **Разделы:** «Попробовать за минуту» → «Что умеет» → «Как это выглядит» → «Как это работает» (Mermaid) → четыре способа сохранить → быстрый запуск → своя установка → «Для компаний» (таблица облако / своя установка / коммерческая) → ограничения → статус и планы → документация → участие → безопасность → лицензия → история звёзд.
- **Факты** взяты только из прежних README, [status.md](../../status.md), [CHANGELOG](../../../CHANGELOG.md), [roadmap](../../roadmap.md), [privacy](../../legal/privacy.md) и [COMMERCIAL.md](../../../COMMERCIAL.md). Комментарии и реакции в README не упомянуты: на hosted они не выложены, и их формат ещё решается.
- **Файлы сообщества:** формы issues вместо markdown-шаблонов (`bug.yml`, `feature.yml`, в `config.yml` — SECURITY.md, FAQ и SUPPORT.md), новый [SUPPORT.md](../../../SUPPORT.md), в кодексе поведения — адрес hello@polochka.app. FUNDING.yml не добавлен: спонсорства нет, есть коммерческая лицензия. GitHub Actions не добавлены.
- **Картинка для соцсетей:** `docs/assets/social-preview.svg` → `social-preview.png` (1280×640) командой `node scripts/render-readme-assets.mjs social`, в стиле карточек `docs/design/og`.

## Что не взяли

- Таблицу содержания: разделы короткие, GitHub сам показывает оглавление по заголовкам.
- Бейджи звёзд, загрузок, Discord, «PRs welcome»: пока нечего показывать, а пустые цифры работают против.
- Аватары участников (contrib.rocks): один мейнтейнер.
- GIF вместо скриншота: интерактив хорошо виден на живом сайте, а GIF тяжёлый и быстро устаревает.
- Сравнение с конкурентами по пунктам: без проверенных данных о чужих продуктах это было бы выдумкой.
