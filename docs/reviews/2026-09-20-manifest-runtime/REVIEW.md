# Manifest и локальная проверка runtime

20.09.2026. Разработка: Luna — валидатор, Sol — запись manifest, Astra — независимое ревью, ведущий — интеграция и браузерные проверки.

## Реализовано

- Строгий manifest v1, canonical JSON/hash, ограничения paths/files/размеров и provenance. См. [контракт](../../BUNDLE_SPEC.md).
- Новые single-HTML revisions получают manifest и hash транзакционно с receipt; повтор запроса сохраняет прежний результат. Старые данные не переписываются. Миграция 006 применена локально.
- Viewer выдаёт документ только для iframe navigation с Fetch Metadata и действительным capability. Это дополнительное ограничение браузерного контекста, не замена авторизации.
- 47 обычных тестов, 6 live tests, TypeScript и build прошли. Логи рядом. Замечание Astra о завершающих LF/CR/CRLF в path/hash/timestamp исправлено Luna; добавлен регрессионный тест, полный прогон 47/47 прошёл после исправления. TypeScript повторно проверен.

## Браузерные наблюдения

В реально сохранённых HTML проверены переключение слайда на 2/3 и чекбокс планировщика 0/1 → 1/1 → 0/1. Вместе с ранее проверенными калькулятором и графиком это четыре типа взаимодействий, а не приёмка всего корпуса.

Сохранённый observable-probes показал SecurityError для parent DOM/localStorage, popup denied, CSP events для connect-src, script-src-elem и img-src. Form, CPU, WebRTC, redirects и другие браузеры ещё не приняты.

Self-navigation к локальному счётчику завершилась заблокированным iframe; счётчик остался 0. Но положительный контроль прямого открытия счётчика также отклонён браузерной средой ERR_BLOCKED_BY_CLIENT. Этот опыт НЕ доказывает блокировку исходящей сети приложением. Мобильная проверка планировщика не завершена.
