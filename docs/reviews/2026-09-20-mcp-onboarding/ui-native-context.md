# UI → Codex → seen → revoke: принято локально

21.09.2026. Пользователь подтвердил создание context-only подключения на1день и отзыв после проверки. Через настоящую форму `/settings/agents` создано подключение «Codex — проверка UI 21 сентября». У него только context; capture/list/revise/share/manage выключены.

Codex CLI0.153.4 с Luna вызвал настоящий `polka_context` и получил structured scopes `[context]`. UI после обновления показал полученный запрос и время последнего обращения. Затем подключение отозвано через UI. Повторный запуск native Codex отказал на MCP initialize (invalid_token/Auth required, exit1); независимый HTTP initialize с тем же токеном вернул401. Временный файл токена удалён; глобальный config не менялся.

[Машиночитаемый результат](ui-native-context-result.json). Необработанный текст модели ошибочно назвал scopes пустыми, поэтому доказательство основано на MCP tool result и UI, а не итоговой фразе модели. Логи с редактированием секрета остаются в ignored `.local`, сам токен в отчёт не включён.

Это завершает локальную проверку выдачи/подключения/context/seen/отзыва. Создание файлов этим токеном не разрешалось и не проверялось. Capture имеет отдельные прежние доказательства; второй клиент, hosted flow и реальные новые пользователи остаются открытыми.
