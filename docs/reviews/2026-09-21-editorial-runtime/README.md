## Развёрнутый просмотр

Luna добавила разворачивание без перемещения или перезагрузки iframe. После замечания Astra фон временно получает `inert`; исходные атрибуты и прокрутка восстанавливаются при закрытии. Root проверил city в браузере:

- шаг 2 остаётся после expand → collapse, URL iframe не изменяется;
- фоновые ссылки имеют inert ancestor, iframe — нет; Shift+Tab с «Свернуть» не переводит фокус на скрытый фон;
- collapse и stop восстанавливают body overflow и удаляют добавленный inert; stop удаляет iframe;
- Escape работает, когда фокус на кнопке родительской страницы. События из opaque iframe не достигают родителя — там используется видимая кнопка «Свернуть»;
- после мобильной CSS правки при viewport 390×844 frame width равна 390, горизонтального overflow нет, высота каждой из трёх кнопок toolbar 44px. Скриншот проверен: отчёт занимает полную ширину, кнопки разделены, заголовок читается.

TypeScript, build и diff-check прошли. Динамические background portals и восстановление ранее заданного inert проверены по коду; отдельного browser сценария для них пока нет. Это локальная приёмка просмотра, не hosted isolation или полный accessibility audit.
