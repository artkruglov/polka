# Реализация первого P0 после запуска Opus

Дата: 2026-09-14  
Основа: [план Opus](../2026-09-14-opus-production-plan/review.md) и [ревью Fable](../2026-09-14-fable-production-review/review.md).

## Что вошло в срез

- `text/html` добавлен в контракт загрузки. Сервер проверяет UTF-8, похожесть на HTML и классифицирует содержимое как `static`, `limited` или `unsupported`.
- Для HTML создан version-pinned документный endpoint. `static` и `limited` показываются в пустом iframe sandbox с CSP `default-src 'none'`, без скриптов, форм и сети. Простая проверка также отклоняет формы, password-поля, javascript/remote resource URLs и meta-refresh. `unsupported` сохраняется как исходник, но ссылку на него сервер не выпускает.
- Получатель видит HTML через короткоживущий grant, привязанный к конкретной revision. После отзыва ссылки уже выданный grant также не работает.
- Добавлен анонимный endpoint жалоб по токену ссылки с idempotency key. В ответе нет названия, владельца или tenant для закрытой/отозванной ссылки.
- На экране получателя добавлены предупреждение о зафиксированной версии и действие «Пожаловаться». Кнопка открывает минимальную форму с причиной и необязательным комментарием.
- Исправлено возвращение названия в `/api/resolve`; раньше SQL выбирал `a.title`, а ответ читал несуществующее `s.title`.
- Добавлена миграция `003_html_static_and_reports.sql` и регистрация версии в `scripts/migrate.ts`.

## Проверка

Запущены `npm run db:migrate`, `npm run check`, `npm run build`, `npm test` и `git diff --check`.

Интеграционный набор: **16/16**. Новый тест проверяет сохранение static HTML, sandbox-заголовок, выдачу HTML по grant, жалобу без входа и отказ в выпуске ссылки для `unsupported` HTML.

## Что сознательно не объявляется готовым

Это не полноценный HTML runtime: интерактивный JavaScript, внешние ресурсы и ZIP-пакеты ещё не поддерживаются. MCP capture, импорт внешних ссылок, Telegram, серверные реакции/витрина, Yandex Cloud deployment, OIDC и operator moderation queue остаются следующими этапами. `limited` — честный безопасный просмотр исходника; он не обещает рабочие интерактивные действия.

CLI Opus не вернул итоговый текст отчёта, поэтому статус выше подтверждён локальным diff, миграцией и повторным прогоном проверок.
