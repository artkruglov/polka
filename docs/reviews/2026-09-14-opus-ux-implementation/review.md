# Opus: реализация UX `/bring`

Дата: 14 сентября 2026. Claude Code Opus изменил только frontend (`apps/web/src`). Сервер, БД, API-контракты и Lanka не затронуты. Задание — `prompt.txt` в этой папке.

## Что исправлено по критике

| Критика | Решение в интерфейсе |
|---|---|
| Отдельный путь «вставить код» | Два равноправных входа на одной карточке: поле ссылки и зона файла, разделённые «или». Вкладок нет; подсказка у файла: «Код и HTML от агента — это тоже файл» |
| Недоказанные «без VPN» и «5 минут» | Обе фразы удалены. Вместо них: «Копия, а не прокси — при просмотре копии Полка не обращается к исходному сервису» и «Новая версия появится, только когда автор явно обновит ссылку» |
| Экран получателя сразу после сохранения | После «Сохранить приватно» показывается выбор аудитории (радиогруппа «Только я» — текущая, «По ссылке», «В компании»). Кнопка применения меняет текст по выбору; адрес и кнопка «Что увидит получатель» появляются только после открытия доступа. Возврат к «Только я» снова скрывает preview |
| Агент публикует или принимает за человека | Факт в hero, ответ агента в примере диалога («Сейчас его видите только вы»), карточка «Подключение агента»: `Сохранять`, `Читать замечания` / `Публиковать — запрещено`, `Принимать — только человек`. В ревью у кнопки принятия — «У агента такого действия нет» |
| Нет видимой коллаборации | Секция «Замечание → кандидат v2 → принятие человеком»: две страницы, три якоря, замечание к версии/месту, статус открыто/решено, кандидат v2 от агента, сравнение до/после, «Принять v2» (доступно после просмотра сравнения), затем отдельное действие автора «Переключить ссылку на v2» |
| Корпоративная граница без админки | Три карточки: внутренний workspace (SSO, работы у организации, ссылка не даёт членства), аудит (журнал реальных действий этой демо-сессии), offboarding (переключатель «Аккаунт активен/отключён»: сессии и токен агента отозваны, работы остаются, назначение продолжателя) |

## Честность прототипа

- Лента «UI-прототип» под шапкой: проверка, импорт, MCP и сохранение не подключены, адреса и квитанции демонстрационные.
- Проверка ссылки подписана «Демо-проверка»; успех называется «Сохранено приватно · демо»; адрес помечен «адрес-пример»; диалог с агентом — «пример ответа, не реальный вызов»; журнал — «не сохраняется».
- Кандидат v2 создаётся кнопкой «Демо: агент сохраняет кандидата v2».

## Доступность и адаптивность

Нативные `form`, `radio`, `button[aria-pressed]`, `fieldset/legend`; фокус переносится на заголовок нового состояния; статус проверки в `role="status"`; якоря в отчёте — кнопки со скрытым текстом «Место для замечания». Раскладка сворачивается в одну колонку на 1080 и 720 px, поля ввода на мобильном — 16 px. Анимации отключаются общим правилом `prefers-reduced-motion`.

## Согласованный язык

Полка: «Принести работу» (→ `/bring`) и «Загрузить файл» (реальная загрузка); пустое состояние предлагает оба. Вход: «Принести. Открыть доступ. Довести до решения.» и ссылка «Принести работу агента: ссылка или файл». Витрина: «Принести работу», «Принести ссылку или файл».

## Ограничения

- `/review` не выделен в отдельный маршрут: серверный `frontend.ts` отдаёт SPA только для известных путей, а сервер в этой задаче не менялся. Ревью доступно как `/bring#review`.
- Все состояния живут в памяти страницы и сбрасываются при перезагрузке.
- В этой сессии не удалось запустить `npm run check/build/test` и браузер: команды заблокированы правами окружения. Перед коммитом их нужно выполнить вручную.
