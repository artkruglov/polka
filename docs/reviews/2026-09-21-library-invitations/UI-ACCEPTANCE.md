Реальный браузер, отдельная disposable БД, читатель library-reader. В test-only fixture добавлена подмена ответа только POST live-view/prepare-live-view через локальный fault-файл. Это проверка UI-контракта, не замена серверных ACL/квот тестов.

- 404: «Этот выпуск больше недоступен…», только закрытие, без повтора и iframe.
- pending: «Подготовка уже выполняется», ручная «Проверить готовность».

- 429: сообщение о лимите, явная кнопка повтора.
- failed: «Не удалось подготовить просмотр», явная «Подготовить повторно».
