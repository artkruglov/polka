# Fable · value-first landing review

Дата: 2026-09-14

## Решение

Первый экран теперь объясняет результат для автора и получателя, а не перечисляет функции:

> Сделали в чате — отправьте ссылку, которая откроется у получателя.

Полка сохраняет независимую копию HTML-страницы, чтобы получателю не требовались VPN, аккаунт или доступ к исходному Claude/ChatGPT. Автор может вернуться к копии, отправить новую версию или отозвать ссылку.

## Что изменено

- Hero и финальный CTA переписаны языком результата.
- Proof-блок рядом с первым действием явно показывает три снятых барьера: без VPN, без аккаунта, без входа в исходный сервис.
- Поле импорта говорит о действии и результате: «Вставьте ссылку — мы сохраним страницу для вас».
- Основной путь назван результатами: сохранить свою копию → получить рабочую ссылку → отправить тому, кому нужно.
- Блок для двух сторон подчёркивает: получатель открывает, автор не теряет работу.
- Telegram, MCP и галерея остаются ниже как ускорения и вторичный discovery-сценарий.

## Ограничения формулировок

Мы не обещаем безусловную доступность из любой сети и не называем ссылку секретной. «Без VPN» означает, что сохранённая копия не обращается к Claude/ChatGPT; доступность самого хостинга зависит от его размещения. Telegram-бот и MCP пока прототипированы в интерфейсе и не запущены на сервере.
