# Fable: jobs, первые пользователи и staged adoption

Дата: 14 сентября 2026.

Финальная гипотеза после обсуждения с владельцем: Полка помогает сохранить результат, созданный в AI-чате, и отправить его человеку, который не может открыть исходную ссылку. Витрина и работа с агентами расширяют этот сценарий после первого полезного действия.

## Jobs map

| Уровень | Trigger | Нужный результат | Тревога пользователя | Самое маленькое ценное действие | Метрика перехода |
|---|---|---|---|---|---|
| P0 · открыть | Друг прислал Claude/GPT-ссылку, а она не открывается | Увидеть страницу в браузере | «Придётся ставить VPN, входить или просить файл» | Открыть `/s/<token>` и увидеть зафиксированную версию | успешное открытие shared link; время до первого экрана |
| P0 · сохранить | Артефакт уже сделан в чате и теряется в истории | Получить независимую копию | «Ссылка сломается, а данные уйдут наружу» | Вставить ссылку или загрузить HTML/ZIP → preview → «Сохранить на Полку» | save completion / preview; доля отказов по причине закрытого источника |
| P0 · поделиться | Копия сохранена, её нужно отправить другу/коллеге | Стабильная ссылка на конкретную версию | «Получатель не откроет или увидит новые правки случайно» | «Поделиться ссылкой» → копировать адрес версии | share creation; recipient open; revoke rate |
| P1 · найти | Через неделю нужно вернуть свой трекер, отчёт или дашборд | Личная библиотека и версии | «Не помню, в каком чате и какая версия актуальна» | Открыть «Моя Полка», поиск по названию/типу | 7-day return; repeat open; version lookup |
| P1/P2 · показать | Есть полезный пример для других людей | Публичный снимок по теме | «Личные данные попадут наружу, будут жалобы» | «Отправить в примеры» после preview, redaction и проверки | approved submissions; useful reactions; complaint rate |
| P2 · автоматизировать | Автор каждый раз скачивает результат вручную | Агент сохраняет результат сам | «Агент получит лишний доступ» | Один раз подключить skill/MCP и сказать «сохрани на Полке» | connected agents; capture success; denied-action rate |
| P3 · работать командой | Команда хранит результаты агентов в разных чатах | Общая библиотека с ролями и аудитом | «Сотрудник ушёл, данные утекли, права неясны» | Войти в workspace компании и сохранить работу | active teams; weekly team retention; ACL incidents |
| P4 · развернуть | Данные нельзя отдавать hosted-сервису | Тот же продукт внутри контура | «Нет SSO, аудита и контроля исходящего трафика» | Запустить self-hosted пакет и подключить внутреннего агента | pilot activation; successful backup/restore; audit coverage |

Главный переход для первого выпуска: **shared link opened → artifact saved → link shared**. Ремикс не используется как activation event и не должен быть главным CTA.

## Кому нужен первый выпуск

Первичные сегменты:

1. **Люди, которые регулярно получают AI-артефакты.** Им не нужно объяснять, как создавать страницу; они сразу чувствуют боль «ссылка из Claude не открылась». Получатель становится новым автором после сохранения.
2. **Авторские power users Claude/ChatGPT.** Они создают много отчётов, планировщиков и дашбордов и хотят один раз получить ссылку, которая живёт дольше чата.

Сообщества здоровья, образования, личной эффективности и данных подходят для публичной витрины и SEO-примеров, но не являются доказанными первичными сегментами. Корпоративные команды — канал пилотов, а не источник массового self-serve-трафика на старте.

## Growth loops и touchpoints

### Loop shared link

Автор сохраняет артефакт → получает `polka.example/s/...` → отправляет другу → получатель открывает без аккаунта исходного агента → видит лёгкое действие «Сохранить себе на Полку» после просмотра. Просмотр остаётся anonymous; сохранение и создание ссылки требуют входа или одноразового magic-link. В ссылке всегда закреплена версия, а отзыв закрывает её немедленно.

### Telegram loop

На сайте и в share-card есть «Отправить в Telegram». Бот принимает публичную ссылку Claude/ChatGPT или HTML/ZIP, проверяет размер и источник, создаёт личную копию и возвращает адрес. Общую ссылку бот включает только после явной кнопки/команды владельца. Бот не принимает cookies, пароли, закрытые ссылки, исполняемые файлы и сообщения из групп.

Минимальный контракт бота:

```text
/start → одноразовая привязка к Polka
ссылка или файл → «Проверяю» → «Сохранил, версия 1»
кнопка «Включить ссылку» → адрес /s/…
/revoke → отзыв последней ссылки с подтверждением
/stop → отвязка Telegram
```

В текущем прототипе бот не существует: `/bring#telegram` показывает только его будущий happy path. Telegram — быстрый транспорт готового результата; MCP — подключение агента, которое позволяет сохранить результат непосредственно из чата.

### Public examples loop

Редакционные примеры по темам (здоровье, дети, финансы, исследования, данные, образование) открываются без входа. Карточка ведёт к «Открыть», «Полезно», «Отправить». Подача пользовательской работы идёт через отдельный preview, обезличивание, подтверждение прав и модерацию. Публичная витрина не открывает личные Полки и не индексирует закрытые ссылки.

### Agent loop

После повторного сохранения пользователь видит приглашение подключить агентский skill/MCP. Pairing проходит в браузере, capability ограничены tenant/workspace, capture по умолчанию private, расширение аудитории требует подтверждения. MCP не заменяет Telegram: первый убирает ручное скачивание, второй нужен для пересылки уже готового результата.

## Staged roadmap

| Фаза | Входит | Не делать | Go/no-go |
|---|---|---|---|
| P0 · share/open/save | безопасный viewer, shared link на immutable revision, preview, save/import файла, минимальный landing, recipient | публичная соцсеть, редактор, обязательный MCP, сложные папки | 10 приглашённых авторов проходят путь за 2 минуты; ≥80% ссылок открываются; нет private leak |
| P1 · library + bot | Моя Полка, версии, поиск, Telegram-бот, revoke, share-card и UTM | команды, подписки, рекомендации, ремикс-first onboarding | ≥30% получателей возвращаются/сохраняют; abuse и лимиты выдержаны |
| P2 · agent capture | skill/MCP, pairing, receipts, scoped `self/ask/deny`, inbox | встроенный чат и зеркалирование чатов | два реальных MCP-клиента, capture идемпотентен, deny-тесты зелёные |
| P3 · community/team | пользовательская витрина, moderation, reactions, team workspace, ACL | enterprise SSO до доказанной командной пользы | публикация не раскрывает private/team; есть модератор и offboarding |
| P4 · enterprise | self-hosted, SSO/OIDC, audit, egress policy, backup/restore, internal agents | обещания сертификации до проверки | пилот внутри контура проходит security review |

Число 50 000 — цель роста, а не доказанный прогноз. До масштабирования нужно подтвердить activation и retention на малой когорте; платить за трафик до этого не следует.

## Простые guardrails

- Shared links имеют `noindex`, короткое/отзываемое право и pinned revision; содержимое не раскрывается при ошибке токена.
- Telegram хранит только необходимые метаданные, ограничивает размер/частоту, не принимает секреты и не публикует автоматически.
- HTML запускается только в изолированном viewer profile; внешний fetch ограничен allowlist и таймаутом.
- Перед публичной подачей проверяются права и чувствительные данные; личные health/child/finance примеры по умолчанию private.
- Все agent actions идут через policy envelope и audit; расширение аудитории всегда требует human approval или ограниченного поручения.

## Ручная приёмка прототипа

1. Гость открывает `/landing`: первым видит «Сделали в чате — сохраните на Полке и отправьте ссылкой» и кнопку «Сохранить на Полку».
2. `/bring` показывает «Вставьте ссылку или файл — получите постоянную ссылку», затем preview и три состояния: личная копия, ссылка, витрина.
3. `/bring#telegram` показывает happy path бота и помечает его «план / ещё не запущен».
4. `/discover` читается как каталог примеров; ремикс не является первым действием.
5. Получатель shared link видит сохранённую версию без входа в Claude/ChatGPT; отзыв закрывает её.

Изменения UI находятся в `apps/web/src/Landing.tsx`, `ArtifactCaptureDemo.tsx`, `TelegramEntryDemo.tsx`, `PublicGallery.tsx`, `Recipient.tsx` и `SiteChrome.tsx`. Реальные Telegram API, MCP capture и hosted Light ещё не подключены.
