# Opus: точки входа — забрать, переработать, поделиться

Дата: 14 сентября 2026. Claude Code Opus 5 по поручению владельца проверил пять пользовательских путей в текущем прототипе и изменил **frontend** (`apps/web/src`) и документацию. Сервер, БД, API-контракты и маршруты не менялись: новые адреса не добавлены, `/bring?url=…` и `/bring#agent` обслуживаются уже существующим shell для `/bring`. Задание — [prompt.txt](prompt.txt). Продолжает [brand update](../2026-09-14-fable-brand-update/review.md) и [UX `/bring`](../2026-09-14-opus-ux-implementation/review.md). Клиентов, интервью и измерений нет; концепция и словарь — гипотезы для E3/E5.

## Вердикт

Прототип был построен вокруг **автора**, который уже сделал работу и хочет её «положить». Владелец ставит главным другой job: человек нашёл готовую работу (чужую в витрине, по ссылке из Claude/ChatGPT, файлом), хочет **сделать свою версию** и потом показать её. Для этого человека первый экран «Сделали с агентом? Положите на Полку.» отвечал не на его вопрос, основной CTA вёл на MCP-сценарий, который ещё не работает, а переработка была четвёртым шагом цикла и спряталась в диалоге витрины.

Решение: **одна модель для всех входов.** Откуда бы работа ни пришла, результат один — *личная копия*. Главное действие с копией — *переработать*. Дальше два независимых шага: *поделиться ссылкой* и *опубликовать в витрину*.

> **Концепция.** Полка превращает готовую работу из чата с агентом в вашу: забрали → получили личную копию → переработали своим агентом → поделились ссылкой или опубликовали в витрину.
>
> **Первая фраза продукта:** «Возьмите готовую работу — сделайте свою версию.»

## Неясности в словах

| Слова в прототипе | Что путалось | Решение |
|---|---|---|
| «Положить работу», «Принести», «Сохранить себе», «импорт» | Четыре названия одного результата; «положить» звучит как хранение, а не как начало работы; «принести» — непонятно откуда | Кнопка и навигация — **«Забрать»**; результат — **«личная копия»**. «Положи на Полку» остаётся только фразой агенту |
| «Взять за основу» vs «Сохранить себе» | Оба создают копию, но назывались по-разному без объяснения | Оба дают «личную копию». «Взять за основу» — для работы, которая уже на Полке (с отметкой «Основано на…»); «Забрать» — для работы снаружи |
| «Сохранить» (закладка) | Совпадало со «Сохранить себе» (копия) | **«В закладки»**, с подписью «закладка не создаёт копию» |
| «Создать» | В интерфейсе не было, но лендинг обещал «положить» свою работу как главный путь | Полка не создаёт с нуля: создание — у агента, дальше «положи на Полку». Вторично |
| «Показать людям», «Показать всем», «Кому показать» с пятью аудиториями | Выбор из пяти режимов сразу после сохранения; «Показать всем» и «По ссылке» стояли рядом как равные | Три состояния: **«Моя личная копия» / «Поделиться ссылкой» / «Опубликовать в витрину»**. «Одному человеку», «Команде», «В компании» — вторичные, свёрнуты |
| «Подключения» | Звучит как настройка, скрывает, что это про агента; вела на поручения, а не на подключение | «Агент», ведёт на `#agent` с честным статусом |

## Что первым

1. **Первый экран:** обещание переработки + поле ссылки + «Забрать и переработать». Второе — «Загрузить HTML или ZIP» и «Взять за основу в витрине».
2. **Цикл:** забрать → личная копия → переработать → поделиться/опубликовать. Фраза агенту — альтернативный вход, не шаг.
3. **Витрина:** примеры, которые можно взять за основу (с подписью «можно взять за основу / только просмотр»).
4. **Три состояния** работы, затем «чем не диск», сегменты, доверие, честные ограничения.

## Что остаётся заглушкой

- `/bring`: проверка ссылки, предпросмотр (демо-дашборд вместо реальной работы), создание копии, «Загрузить свою версию», ссылка, отправка снимка на проверку и прочие аудитории — локальные состояния страницы. `import.preview/commit` не подключены.
- MCP: адреса подключения нет; блок `#agent` описывает будущие шаги и прямо говорит «ещё не запущено». Поручения агенту (`#connections`) — прежний демо-сценарий.
- Витрина: 10 редакционных демо; «Взять за основу», «Полезно», «В закладки» — отметки вкладки; «Отправить» копирует реальный адрес `/discover/<id>`.
- Получатель `/s#…`: страница реальная (API ссылок), но «забрать себе копию по ссылке» — только текст «скоро»; запрос доступа — сообщение для копирования, Полка его не отправляет.
- Моя Полка: «Переработать» — текст запроса агенту и существующая загрузка новой версии (реальный API; HTML в текущем срезе не принимается); «Опубликовать в витрину» — подпись «скоро».

## Риски

1. **Права на чужую работу.** Главный CTA «забрать чужую работу» подталкивает копировать то, что человеку не принадлежит. Личная копия допустима как у закладки/скачивания, но публикация копии без переработки и указания автора — риск для витрины. В прототипе — предупреждение на шаге публикации для работ, забранных по ссылке; нужно правило модерации и поле «Основано на» для внешних источников (F52).
2. **Обещание доступности.** Владелец формулирует ценность как «открыть без VPN». Интерфейс по-прежнему не пишет «без VPN» (коммит 5175c50, E2): говорим об устройстве — «открывается с Полки, исходный сервис при просмотре не нужен». Если E2 подтвердит доступность из целевых сетей, формулировку можно усилить.
3. **Импорт по ссылке — эксперимент E4.** Первый экран теперь опирается на поле ссылки, а его работоспособность зависит от провайдеров (Claude public artifacts, ChatGPT). Если E4 даст no-go, первым входом должен стать файл HTML/ZIP; поле ссылки в hero тогда меняется на зону загрузки без смены концепции.
4. **Переработка вне Полки.** «Переработать» сейчас — копирование запроса и ручная загрузка новой версии. Без MCP это несколько ручных шагов (скачать, отдать агенту, загрузить). Метрика «копия → версия 2» (F53) покажет, не обрывается ли путь здесь.
5. **Сдвиг от автора.** Автор своей работы теперь видит себя во второй строке («Сделали работу сами? Скажите агенту…»). Если E3 покажет, что основной приток — авторы, а не переработчики, порядок нужно вернуть.
6. **Слово «Забрать».** Может читаться как «унести у автора». Альтернативы — «Добавить», «Взять себе». Проверить в E5 вместе с «Витрина».
7. **Иконки без подписей на карточке витрины.** «Полезно» и «Отправить» — иконки с `aria-label` и `title`; на телефоне подсказка `title` не видна. Если E5 покажет, что «Отправить» не находят, вернуть текстовые подписи.
8. **Проверки не запускались** (см. ниже) — изменения проверены только чтением.

## Ручной сценарий приёмки

Открыть локальную сборку (`npm run build`, `npm run dev`, `http://127.0.0.1:4390`) на 1440 и 360 px.

1. **Лендинг гостя (`/`).** Первый экран без прокрутки: заголовок «Возьмите готовую работу — сделайте свою версию.», поле «Ссылка на работу из Claude или ChatGPT», основная кнопка «Забрать и переработать». Нет слов «без VPN», «MCP», «артефакт». На 360 px кнопка под полем на всю ширину.
2. Вставить `https://claude.ai/public/artifacts/quarterly-report` → Enter. Открывается `/bring?url=…`, проверка стартует сама, поле заполнено.
3. **Предпросмотр.** Видны «Предпросмотр · копия ещё не создана», окно «claude.ai → Полка · ваша копия» с работающим дашбордом (переключается период), «Что получите: личную копию · видите только вы». Основная кнопка — «Переработать эту работу».
4. Нажать «Переработать эту работу». Заголовок «Квартальный отчёт · версия 1», фокус на заголовке; строка трёх состояний: «Моя личная копия · есть», «Поделиться ссылкой · выключено», «Опубликовать в витрину · скоро»; раскрыта карточка «Переработать» с запросом агенту и кнопкой «Скопировать»; есть строка «Подключение агента к Полке ещё не запущено».
5. «Загрузить свою версию · демо» → заголовок «версия 2», текст «Ссылка и витрина сами не обновляются», шаг «Переработать» отмечен.
6. «Поделиться ссылкой» → «Создать ссылку на версию 2» → адрес-пример, состояние «включено», «Что увидит получатель» показывает «Открыто по ссылке · без входа» и «аккаунт Claude или ChatGPT не нужен». Раскрыть «Переработать» и снова «Загрузить свою версию» → раскрыть «Поделиться ссылкой»: в карточке «По ссылке открывается версия 2, у вас — версия 3» и «Обновить ссылку до v3».
7. «Опубликовать в витрину · скоро» → предупреждение о правах на чужую работу → «Отправить снимок v3 на проверку · демо» → «на проверке». Раздел «Компания → Аудит» ниже содержит события копии, версий, ссылки и снимка.
8. «Забрать другую работу» → демо-ветка «закрытая ссылка» → «Нужен вход в исходный сервис», предложение загрузить файл. Загрузка любого `.html` → предпросмотр с именем файла.
9. **Агент (`/bring#agent`, пункт «Агент»).** Страница прокручивается к «Скажите агенту: «Положи на Полку»», карточка MCP «Ещё не запущено», три будущих шага, «Что делать сейчас» с кнопкой к форме. Нигде нет адреса подключения. Раздел поручений `#connections` работает как раньше.
10. **Витрина (`/discover`) гостем.** На карточке первым «Взять за основу», затем «Полезно» и «Отправить». «Отправить» открывает диалог с адресом `/discover/<id>` и «Скопировать». «Взять за основу» открывает диалог без перехода на вход: «Вы не вошли…», кнопки «Что будет дальше» и «Войти и взять за основу». Вторая ведёт на вход с плашкой «После входа: взять за основу «…»». «Полезно» гостем ведёт на вход с намерением.
11. **Страница работы гостем (`/discover/week-planner`).** Панель: «Взять за основу» + пояснение, ряд «Полезно / Отправить / В закладки», «Закладка не создаёт копию». Для `/discover/churn-board` — «Автор разрешил только просмотр», кнопки «Взять за основу» нет.
12. На лендинге кнопка «Взять за основу» под живым калькулятором открывает тот же гостевой диалог на `/discover/mortgage-calc`.
13. **Вход и Моя Полка.** Войти (`npm run account:create`). Пустая полка: «Забрать работу», «Взять за основу в витрине», «Загрузить файл с компьютера», «Подключение агента — скоро». Загрузить текст → страница работы: строка трёх состояний («Поделиться ссылкой · выключено»), кнопки «Переработать» и «Поделиться ссылкой». «Переработать» → запрос агенту → «Загрузить новую версию» открывает прежнюю панель новой версии и сохраняет v2. «Поделиться ссылкой» → включить ссылку → строка показывает «включено»; после новой версии — «по ссылке старая версия».
14. **Получатель.** Скопировать ссылку, открыть в приватном окне: работа, «Работа на Полке, открыта по ссылке», «Хотите свою версию? · скоро». Закрыть ссылку у владельца, обновить окно получателя: «Работа по этой ссылке недоступна», «Запросить доступ у автора» с сообщением и «Скопировать», ссылка в витрину; название работы не показывается.
15. **Регрессия маршрутов.** `/landing`, `/connections`, `/works/<id>`, `/discover/<id>`, `/s#…` открываются; `npm test` зелёный.

## Проверка

`npm run check`, `npm run build`, `npm test` и локальный `tsc` в этой сессии не запущены: окружение требует ручного подтверждения этих команд, и оно не было получено. Код проверен чтением на strict TypeScript: иконки lucide сверены с `lucide-react.d.ts`, значения `share.status` — с `packages/contracts`, CSS-переменные — со `style.css`/`community.css`. Перед коммитом обязательны три команды выше и ручной сценарий приёмки на 360/768/1440 px.
