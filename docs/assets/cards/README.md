# Полка — рекламные карточки

16 JPEG (сжаты из PNG, качество 85): восемь сюжетов, каждый в размерах 1600×900 (16:9) и 1080×1350 (4:5). Изображения созданы встроенным `image_gen` по предоставленным референсам.

## Проверка

Все 16 изображений просмотрены: проверены заголовки, подписи интерфейса, буквы «ё», URL и отсутствие обрезанного текста. Неразборчивых или ошибочно написанных слов при визуальной проверке не обнаружено. Автоматическое OCR через macOS Vision завершилось ошибкой среды; заключение о тексте основано на визуальной проверке.

В обеих карточках 03 генератор добавил точку после «Ссылка без аккаунта». Ниже приведён фактический текст с этой точкой. Остальные заданные фразы воспроизведены без замеченных текстовых ошибок. Переносы строк зависят от формата, сами слова и адреса сохранены.

Знак «п» на полке присутствует во всех изображениях. Списки ниже содержат все текстовые надписи; повторяющаяся надпись перечислена один раз. Пиктограммы стрелок, копирования, ссылок и условные полосы в превью не являются текстом. В карточке 06 также изображён символ кода `</>`.

Макеты интерфейса — рекламные иллюстрации по мотивам предоставленных скриншотов. Графики условные, без числовых утверждений. «Агент 1», «Агент 2» и «Агент 3» обозначают условные источники работ.
