# Дорожная карта

Обновлено 22.09.2026. Цель ближайших этапов: **ссылка на артефакт → работа показана на Полке**. Сервер Полки не может сам забрать артефакт по ссылке Claude или ChatGPT ([FAQ](faq.md#почему-нельзя-вставить-ссылку-на-артефакт-claude-или-chatgpt)). Автоматический перенос возможен только двумя законными путями: код передаёт сама модель (коннектор) или браузер пользователя, у которого есть доступ (расширение).

| Этап | Результат | Состояние |
|---|---|---|
| 1. Рестайлинг и честный путь для ссылок | Единая система токенов и компонентов. Ссылка Claude/ChatGPT распознаётся, Полка объясняет причину, а файл можно бросить прямо в карточку | Сделано |
| 2. Интерактивный viewer в облаке | Режим `production`, второй домен polochka.page. Интерактивные страницы работают у получателя, «Интересное» публикуется интерактивным | Сделано |
| 3. «На Полку» из Claude.ai и ChatGPT | OAuth 2.1 (PKCE, DCR, protected-resource metadata), `polka_publish` возвращает ссылку, React runtime для артефактов из чата | Сделано. В Claude.ai сохранение и ссылка проверены на polochka.app 22.09.2026; осталось проверить отзыв подключения и ChatGPT ([чеклист](MCP_CONNECTOR.md#приёмка-после-выкладки)) |

| 5. Эксплуатация пилота | Вход по почте (SMTP), мониторинг и алерты, проверка восстановления на отдельной VM | Следующий |
| Позже | Telegram-бот; публикации авторов и модерация; командные аккаунты и SSO | По спросу |

## Чего не делаем

Встроенный чат или генератор, редактор в духе Figma, биллинг, Kubernetes. Не обещаем импорт любой ссылки и доступность «из любой сети». Корпоративные требования (SSO, политика egress, аудит) ждут отдельного пилота.

## Как меняется план

Продуктовые границы описаны в [specs/PRODUCT.md](specs/PRODUCT.md) и [specs/REQUIREMENTS.md](specs/REQUIREMENTS.md), принятые решения — в [specs/DECISIONS.md](specs/DECISIONS.md). Этап считается сделанным, когда код покрыт тестами и работает на polochka.app. Текущее состояние по функциям — в [status.md](status.md).
