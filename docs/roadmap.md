# Дорожная карта

Обновлено 09.10.2026. Цель ближайших этапов: **агент сохраняет работу сам, а ссылка на неё открывается у любого получателя**. Сервер Полки не может сам забрать артефакт по ссылке Claude или ChatGPT ([FAQ](faq.md#почему-нельзя-вставить-ссылку-на-артефакт-claude-или-chatgpt)), поэтому с 25.09.2026 веб-интерфейс сохранение по ссылке не предлагает: работу передаёт агент (коннектор, плагин, MCP) или человек файлом. Импорт по ссылке и расширение браузера остаются экспериментом в коде.

## Открытые задачи

Задачи открытого ядра ведутся в [GitHub Issues](https://github.com/artkruglov/polka/issues). По направлениям:

- [полки и команды](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Aarea%3Ashelf), [сессии агентов](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Aarea%3Asessions), [эксплуатация](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Aarea%3Aops), [удобство разработки](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Aarea%3Adx), [документация](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Aarea%3Adocs);
- [можно брать](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3Astatus%3Aready), в том числе [для первого вклада](https://github.com/artkruglov/polka/issues?q=is%3Aopen+label%3A%22good+first+issue%22);
- ждут пилота или решения владельца — метки `status:blocked-pilot`, `status:after-conversations`, `status:blocked-owner`.

Задачи коммерческой редакции — в её приватном репозитории. Что уже сделано по версиям — в [CHANGELOG](../CHANGELOG.md), состояние по функциям — в [status.md](status.md).

## Чего не делаем

Встроенный чат или генератор, редактор в духе Figma, биллинг, Kubernetes. Не обещаем импорт любой ссылки и доступность «из любой сети». Корпоративные требования (SAML, SCIM, политика egress, аудит) ждут отдельного пилота.

## Как меняется план

Продуктовые границы описаны в [specs/PRODUCT.md](specs/PRODUCT.md) и [specs/REQUIREMENTS.md](specs/REQUIREMENTS.md), принятые решения — в [specs/DECISIONS.md](specs/DECISIONS.md). Этап считается сделанным, когда код покрыт тестами и работает на polochka.app. Этапы 3 (ChatGPT-коннектор, отзыв подключения не проверены), 4 (расширение не в магазине), 6 и 7 (полки отделов и сервисные доступы выключены в облаке до пилота) этому пока не соответствуют: они «в коде», а не «сделаны». Все проверки `npm run verify`, включая живой набор и права ролей БД, GitHub Actions выполняет на каждый pull request. Текущее состояние по функциям — в [status.md](status.md).
