# Дорожная карта

Обновлено 25.09.2026. Цель ближайших этапов: **ссылка на артефакт → работа показана на Полке**. Сервер Полки не может сам забрать артефакт по ссылке Claude или ChatGPT ([FAQ](faq.md#почему-нельзя-вставить-ссылку-на-артефакт-claude-или-chatgpt)). Автоматический перенос возможен только двумя законными путями: код передаёт сама модель (коннектор) или браузер пользователя, у которого есть доступ (расширение).

## Чего не делаем

Встроенный чат или генератор, редактор в духе Figma, биллинг, Kubernetes. Не обещаем импорт любой ссылки и доступность «из любой сети». Корпоративные требования (SAML, SCIM, политика egress, аудит) ждут отдельного пилота.

## Как меняется план

Продуктовые границы описаны в [specs/PRODUCT.md](specs/PRODUCT.md) и [specs/REQUIREMENTS.md](specs/REQUIREMENTS.md), принятые решения — в [specs/DECISIONS.md](specs/DECISIONS.md). Этап считается сделанным, когда код покрыт тестами и работает на polochka.app. Текущее состояние по функциям — в [status.md](status.md).
