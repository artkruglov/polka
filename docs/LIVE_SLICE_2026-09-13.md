# Первый рабочий срез Полки

13 сентября 2026. Продолжение D0 → D1/D2. Статус: **локальный development build**, M0/M1 целиком не закрыты.

## Что заработало

В новом репозитории созданы React/TypeScript приложение, общий контракт входов/DTO, модульный API, миграции PostgreSQL и независимый адаптер S3. UI разделён на полку/работу, вход, preview, upload, share и reader; строковый рендерер/глобальная demo-модель старого макета не перенесены. Палитра, формы, тексты и состояния продолжают принятое ревью Opus. Новый вызов Opus в этом срезе не выполнялся.

Путь J01/J04/J05/J06 реализован для PNG/JPEG/WebP/TXT: настоящий вход → папка → сохранение → просмотр → явная ссылка → другая версия → обновление ссылки → отзыв. Источник истины — PostgreSQL и S3, а не состояние вкладки. Демонстрационный макет на 4388 остаётся отдельным; рабочее приложение на 4390.

## Приёмка

| Проверка | Результат |
|---|---|
| TypeScript + production UI build | Прошли; lockfile закрепляет зависимости |
| Интеграционные тесты | 15 passed с настоящими PostgreSQL/S3, отдельные аккаунты |
| Save/reload | Материал и обе версии доступны после перезагрузки страницы |
| Save/share/publish | v2 не переключает ссылку автоматически; читатель с открытой v1 её сохраняет; новый resolve после publish получает v2 |
| Revoke | Повторное открытие даёт общий отказ без названия работы; действующие grants также проверяются сервером |
| Перезапуск | Процесс API и оба контейнера перезапущены; сессия, каталог, bytes, v1/v2 и отозванная ссылка сохранились |
| Обновление frontend | Исправлена раздача файлов, появившихся после старта сервера; отдельный регрессионный тест. Missing asset возвращает 404, а не HTML |
| Mobile | 390×844: история, панель доступа и меню; desktop 1280×720. Фактическая ширина проверялась по DOM |
| Повреждённая/оборванная загрузка | Неверные bytes/hash/type отклоняются; retry и finalize race дают один receipt |
| Storage/DB разрыв | Повтор после put до DB commit повторно использует точные immutable bytes; cleanup сохраняет committed revisions |

Браузерные шаги выполнены вручную инструментами управления браузером; тестовый reader в отдельной вкладке того же браузера, а анонимный доступ проверен отдельными HTTP-сессиями. Смена двух реальных аккаунтов дополнительно пройдена в браузере: второй пользователь не видит папку и материалы первого. Это не реальные интервью. Снимки в [evidence](evidence/live-slice-2026-09-13/). В screenshot evidence нет действующей share-ссылки или пароля.

## Осознанные ограничения

Срез доказывает хранение и переходы доступа. Он пока не доказывает главный визуальный HTML-сценарий. Произвольный HTML не исполняется и не выдаётся как «безопасный» через iframe. Plain text — самостоятельный поддержанный тип, не новый презентационный DSL.

Аккаунты создаёт оператор; email/IdP/invited/company не реализованы. Нет папочной иерархии, корзины, публичного каталога, копирования чужих работ, pinned link UI, редактора HTML, MCP/агентского чата, резервного восстановления, app Docker image и внешнего deployment. Локальный S3 fixture не выбран как обязательный корпоративный storage. Нагрузочные SLO и удалённый доступ не проверены.

Нет второго demo adapter для React: принятую модель D0 сохранили как исследовательский инструмент, а минимальный новый UI сразу связали с HTTP-контрактом. Это сокращает число параллельных реализаций одного поведения; серверные инварианты проверены независимо от UI.
