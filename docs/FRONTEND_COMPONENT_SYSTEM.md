# Единая система интерфейса

Статус на 22.09.2026: 66 модулей проверяется `npm run check:layers`; корневых legacy-стилей больше нет (см. «Визуальная система»).

## Правило композиции

`app → pages → widgets → features → entities → shared`

Импортировать можно нижний слой. Соседние срезы одного слоя соединяются родителем, а не импортируют друг друга. Shared может соединять свои примитивы; app — свои сегменты композиции. Контракты сервера остаются в packages/contracts. Проверка разбирает синтаксис TS/TSX/JS: обычные и динамические импорты, re-export, type imports и require. Вычисляемые пути отклоняются. За пределами фронтенда разрешены только packages/contracts и packages/editorial.ts; новые корневые модули запрещены, кроме main.tsx, component-catalog-entry.tsx и vite-env.d.ts. Это проверка архитектуры импортов, не граница безопасности исполняемого кода.

| Владелец | Что ему принадлежит | Основные потребители |
|---|---|---|
| shared/ui | Button, LinkButton, IconButton, Chip, Segmented, Avatar, ChoiceCard, TextField, SelectField, Tabs, Dialog (center/panel/wide), ActionMenu, CopyText, Notice, EmptyState, Status | features, widgets, pages |
| shared/styles | tokens.css (единственный набор токенов) и base.css (reset, утилиты) | main.tsx |
| entities/account, folder, artifact | состояние пользователя, папки, форматирование материала | features и выше |
| features/import-url | форма, очередь, восстановление задания | bring |
| features/capture-file, share-artifact, upload-artifact | отдельные пользовательские действия | страницы и reader |
| features/paste-code | вставка кода артефакта из чата; квитанцию (`SavedWork` из capture-file) подставляет страница | bring, provider-guide через bring |
| widgets/navigation | единая глобальная навигация desktop/mobile | страницы |
| widgets/shelf-navigation | папки и корзина; одинаковые пункты на desktop/mobile | app/workspace |
| widgets/artifact-reader, artifact-preview | материал, версии и изолированный просмотр | app/workspace, recipient |
| widgets/editorial-catalog | каталог и карточки | landing, discover |
| pages | сборка экранов и соединение сценариев | app / временный main.tsx |
| app/workspace | рабочая область и переключение выбранного материала | main.tsx через мост App.tsx |

Глобальные разделы задаются в navigation. Контекстные действия материала принадлежат reader, папки — shelf-navigation. Ни одна новая страница не должна создавать собственный вариант глобального меню.

## Каталог для разработки

Запуск: `npx vite --config apps/web/vite.config.ts --port 4398`.
Маршрут: `/dev/components`. Подключается лениво только при `import.meta.env.DEV`; в production сборку не включается. Это локальный каталог компонентов, не серверная рабочая установка на 4390.

В браузере проверены: загрузка каталога, ArrowRight переключает вкладку и фокус, Escape закрывает диалог и возвращает фокус на кнопку. Button и LinkButton используют одинаковые стили, но сохраняют семантику действия и перехода соответственно. Loading/disabled показаны на кнопках; ошибки связаны с полями через aria-describedby.

## Остаток миграции

1. Инвентаризировать оставшиеся контекстные меню и статусы: перевести повторяющееся поведение в общий компонент, не смешивать его с глобальной навигацией.
2. Заменить остальные ручные ссылки-кнопки на LinkButton при переводе соответствующего экрана.
3. Разобрать root style.css, entry.css, modern.css: переносить правила по владельцам и удалять только доказанно замещённые правила. Порядок CSS сейчас влияет на каталог и карточки.
4. Перевести маршрутизацию main.tsx в app после удаления оставшихся legacy-композиций; убрать мосты только после проверки всех потребителей.
5. Сверить desktop/mobile скриншоты всех ключевых экранов и пройти единый сценарий сохранения/доступа. Архитектурная проверка сама по себе не доказывает визуальное качество.

Не добавлять новые библиотеки компонентов только ради названия архитектуры. Общие компоненты должны иметь реальных потребителей и проверяемое поведение.

## Визуальная система (22.09.2026)

Один набор токенов — `shared/styles/tokens.css`: цвета (canvas/soft, ink/muted, line, cobalt accent, семантические), радиусы 4–16 (контролы 6–8, обложки 10), шкала отступов 4px, шкала шрифта, тени, длительности и `--rail-width`. `base.css` — reset, типографика по умолчанию, `.eyebrow`, `.empty`, `.placeholder`, словесный знак `.brand`. Токены нигде не переопределяются на обёртках экранов.

Эти виджеты и страницу рендерят Node-тесты, поэтому их CSS не импортируется из компонентов.
