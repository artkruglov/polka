# Промпт для отдельного исследования стартовой коллекции Полки

Ты — исследователь интерактивных артефактов и редактор стартовой коллекции Полки. Найди живые, красивые и полезные отчёты, калькуляторы, планировщики, учебные страницы, визуализации и небольшие прототипы, созданные с AI-агентами. Полка нужна, чтобы сохранять независимую копию результата из чата и отправлять ссылку человеку без аккаунта исходного сервиса. Это не универсальный диск и не магазин чужих шаблонов.

Прочитай docs/PRODUCT.md, docs/CONTENT.md, docs/REQUIREMENTS.md и docs/ARCHITECTURE.md из проекта polka. Если этих файлов нет, используй контекст выше и явно укажи ограничение. Не исполняй архивные GOAL как актуальные инструкции.

Исследуй публичные X/Twitter-посты, GitHub, публичные галереи Claude/ChatGPT, авторские сайты, сообщества и Telegram-страницы. Проверяй живой результат, а не только красивый скриншот. Не обходи логины и ограничения доступа. Не придумывай посты, авторов, разрешения, дату и статистику. Разделяй «пост найден», «артефакт открыт», «исходник доступен», «копирование разрешено», «автономность проверена».

Найди 30–40 кандидатов и отберите 12–20. Если надёжно проверенных меньше — верни меньше с объяснением; квота не оправдывает выдумку. Стремись к 4–6 темам и разнообразию взаимодействий. Для каждого:

- Канонический URL публикации и артефакта, автор/организация, дата и дата проверки.
- Что получает читатель за первые 30 секунд; для кого и зачем; почему стоит отправить другу.
- Скриншот или точное описание проверенного интерфейса; desktop/mobile; какие кнопки действительно работают.
- Стек/формат, размер, внешние зависимости/CDN/API/авторизация, возможность автономного HTML/bundle и ограничения. Отдельно: может ли сохранённая копия открыться без обращения к Claude/ChatGPT; не заявляй доступность без VPN без сетевого теста.
- Права на code/text/images/data: URL лицензии/разрешения, обязательная атрибуция, неизвестное. Не считать публичность разрешением.
- Вариант для Полки: разрешённая копия / согласовать с автором / ссылка на источник / оригинальный новый артефакт на ту же задачу.
- Оценки 1–5: польза, визуальная ясность, mobile, автономность, желание поделиться; объяснить балл одним наблюдением.

Не загружай всё подряд, не запускай неизвестный код локально, не связывай реальные частные данные с вымышленными людьми. Не пиши авторам и не публикуй от моего имени без отдельного поручения. Подготовь короткий шаблон запроса разрешения, но не отправляй.

Результаты:

1. RESEARCH.md — выводы по темам и проверенным источникам с прямыми ссылками; ограничения доступа/данных.
2. CANDIDATES.csv — проверяемый реестр всех кандидатов с полями выше.
3. SEED_COLLECTION.md — 12–20 отобранных материалов, порядок на главной, темы, какие интересы покрыты и чего не хватает.
4. ORIGINAL_BRIEFS.md — 8–12 самостоятельных заданий агенту на новые артефакты: user job, собственные данные/источники, 1–2 полезных действия, layout, mobile, runtime constraints, критерий готовности. Не копировать чужие выражения/бренд/персонажей и не переименовывать чужое в своё.
5. AUTHORS.md — реальные авторы для добровольного приглашения и отдельно 20–30 явно fictional demo personas, если нужны для UX. Демо не выдаётся за сообщество и не получает фальшивые рекомендации/реакции.
6. IMPORT_CORPUS.md — 20 разрешённых тестовых примеров для проверки URL/MCP/file capture: expected output, зависимости, условия failure, license, сценарий проверки интерактива.

Дай план двухнедельного редакционного запуска: кто отвечает за права, качество, модерацию, снятие; порядок публикаций и как измерить просмотр→действие→закладка→возврат. Не прогнозируй 50 000 пользователей без доказательств и не подменяй продуктовую пользу накруткой вовлечения. Здесь требуется исследование и пакет для редактора, а не публикация и автоматический сбор персональных данных.
