# Экраны и визуальные правила

| Путь | Сейчас | Что довести |
|---|---|---|
| /landing, гостевой / | Новый лендинг, заметный URL, файл/агент и demo cards | CTA должны совпадать с реальными capabilities и поддержанным источником |
| /discover | 24 synthetic authors, поиск/темы, карточки | 12–20 законченных материалов, разные реальные previews, редакционные подборки |
| /discover/:id | Крупный viewer, local likes/bookmarks, похожее | Не путать React demo с сохранённым HTML; server actions на C1 |
| /discover?author= | Фильтр по вымышленному имени | Отдельный профиль реального автора в C1; демо не выдавать за аккаунт |
| /?login=1 | Только логин/пароль оператора | Signup и mail verification, retry/restore/intended destination |
| /signup, /start | Экраны и local email flow готовы | B1: [детальная спецификация](ONBOARDING_SPEC.md) |
| /bring | Реальная загрузка файла + mock URL | Реальный import state machine, continuity после входа |
| /settings/agents | Отдельный мастер demo | B1 UI, B3 реальное подключение; пункт «Агенты» на видном месте |
| /connections | Длинный демонстрационный набор Telegram/MCP/review/company | Убрать с основного пути подключения; отдельный мастер вместо матрицы |
| / после входа | Хранилище с папками, поиск, пагинация | Единая оболочка, первый результат, простая организация |
| /works/:id | Новый reader текста, версии, ссылка | Дизайн состояний image/HTML/error; live HTML в B2, совместимый mobile |
| /s#token | Настоящий recipient | Единый visual style, revoked/expired/limited, mobile и ограничение previews для unlisted |
| moderation/settings/account | Нет | Operator minimum в B4; публикации C1 |

Дизайн: белая/холодная нейтральная оболочка, cobalt основной action, гротеск, радиусы 6–9 px, тонкие разделители, цвет внутри самого артефакта. Крупное содержание и видимая «Открыть». На мобильном одна колонка и понятный возврат; формы не требуют горизонтальной прокрутки. Наличие красивого изображения не означает pixel-perfect fidelity всех состояний.

В пользовательском интерфейсе только нужные детали. Capability/manifest не нужны на первом экране, но поддержанные форматы, статус сохранения и видимость нужны. Поле «Вставьте ссылку» нельзя вести в успех, если было лишь распознавание hostname. «По ссылке» объясняет пересылку; публичный каталог — отдельное действие. Макет будущей функции маркируется до нажатия.

Отмена прежнего запрета на аватары и реакции не разрешает фальшивую социальную статистику. Демо-активность локальная, авторы вымышлены; реальные callbacks и публикации не подменяются таймерами.

## Состояния, которые нельзя потерять

- «Скачать оригинал» на странице владельца: выбранная версия, формат и размер; экспорт bundle включает manifest (R17).
- Настройки аккаунта: удалить аккаунт, последствия для ссылок, срок очистки и резервных копий. До реализации не показывать ложный успех (R17).
- «По ссылке» в beta означает любого обладателя адреса. «Конкретному человеку» появится только вместе с проверяемыми приглашениями C2 (R19).
- Публикация C1 не включается при обычном сохранении или share. Индексация поисковиками — отдельный выбор; снятие публикации и удаление оригинала различаются (R18).
- Telegram остаётся отдельной точкой входа после beta, использующей общий импорт/MCP capture service; не основной экран настройки агента (R20).
