# PolkaRenderer — робот Полки

PolkaRenderer открывает страницу только тогда, когда пользователь Полки вставил ссылку на неё и нажал «Сохранить». Сам по сайтам он не ходит, ссылки не собирает и сайты не индексирует.

User-Agent: `PolkaRenderer/1.0 (+https://polochka.app/bot)`.

## Что он делает

Пользователь вставляет публичную ссылку, чтобы сохранить копию страницы у себя на полке. Робот запрашивает эту страницу один раз, без повторов, и передаёт её Полке. Полка сохраняет копию приватно, в аккаунте этого пользователя.

Робот открывает только такие публичные адреса:

- сайты на `*.lovable.app`, `*.bolt.host`, `*.replit.app`, `*.github.io` и общие ссылки Gemini `gemini.google.com/share/…` — в изолированном браузере, чтобы сохранить снимок страницы;
- общие ссылки ChatGPT `chatgpt.com/share/…` и `chatgpt.com/canvas/shared/…` — одним HTTP-запросом без браузера;
- публичные артефакты Claude `claude.ai/artifact/…` и `claude.ai/public/artifacts/…` — одна попытка в браузере.

Другие адреса Полка скачивает как обычную HTML-страницу, без выполнения скриптов.

Робот не входит в аккаунты и не передаёт cookies. Он не обходит проверки на бота, CAPTCHA и окна согласия, не подменяет браузер и не меняет IP-адрес. Если сайт показал проверку, пользователь получает ответ «сайт не отдал страницу» и сохраняет её другим способом. Внутренние адреса робот не открывает: частные сети, localhost и адреса облачных metadata-сервисов.

## robots.txt

Перед каждой страницей робот читает `robots.txt` сайта (RFC 9309) и хранит ответ до часа. Сначала он ищет правила для `PolkaRenderer`, если их нет — для `*`. Если `robots.txt` не отвечает (ошибка 5xx или нет соединения), робот страницу не открывает.

Чтобы запретить роботу весь сайт, добавьте в `robots.txt` две строки: `User-agent: PolkaRenderer` и `Disallow: /`. Чтобы запретить часть сайта, укажите её путь, например `Disallow: /private/`.
