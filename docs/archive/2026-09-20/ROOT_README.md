# Полка

**Сделали в чате — сохраните на Полке и отправьте ссылкой.**

Отчёт, дашборд, планировщик или мини-сайт из Claude, ChatGPT или другого агента становится независимой копией на Полке. Его можно открыть в браузере без аккаунта в исходном сервисе, отправить другу постоянной ссылкой и найти позже. Витрина тематических примеров и «Взять за основу» остаются дополнительными сценариями ([решение Fable](../../reviews/2026-09-14-fable-primary-job-correction/review.md)).

Полка — не диск: работы здесь открываются как рабочие страницы, хранятся независимой копией, имеют версии и могут быть взяты за основу с указанием автора.

Две поставки: **Light** — hosted-сервис для авторов и команд 20–40 человек, серверы в России (план; провайдер и доступность из сетей ещё проверяются), простой вход; **Enterprise** — установка внутри контура компании с SSO, внутренними агентами, контролем исходящего трафика, аудитом и offboarding. Мы не заявляем «без VPN», юридическую сертификацию, абсолютную доступность или «данные никогда не покидают Россию». В обеих поставках агент действует по вашему поручению: сохраняет, раскладывает работы и готовит снимок сам, а показать работу другим людям может только после вашего подтверждения или в рамках ограниченного поручения (`self / ask / deny`). Права на материал, модерация, реакции и утверждение остаются за человеком; ссылка не попадает в чат агента, а всех агентов можно остановить одним действием.

**Состояние: первый рабочий локальный срез.** Есть React-интерфейс, отдельные аккаунты, PostgreSQL/S3, загрузка изображений, текста и статического HTML, папки, версии и реальные отзываемые ссылки. Статический HTML показывается в sandbox без скриптов и сети; HTML-runtime/ZIP, MCP, публикация снимков, модерация, hosted Light и Enterprise-поставка ещё впереди. [Отчёт о реализации P0 после запуска Opus](../../reviews/2026-09-14-opus-production-implementation/review.md) · [финальное UX-ревью Opus](../../reviews/2026-09-14-opus-final-review/review.md). Прежний релиз Lanka не является релизом Полки.

**[Запустить локально](LOCAL_DEVELOPMENT.md)** · [Что проверено и что дальше](LIVE_SLICE_2026-09-13.md). Рабочая сборка открывается на `http://127.0.0.1:4390`, публичная витрина демо — на `/discover`, исследовательский макет на 4388 остаётся отдельно.

Интерфейсный срез agent-first входа доступен на `http://127.0.0.1:4390/bring`: файл (real) или ссылка (demo: только распознаётся, импорт не подключён) → проверка → «Сохранить себе» → «Кому показать» («Только я» / «Одному человеку» / «По ссылке» / «Команде» / «В компании», незавершённые режимы помечены «план») → экран получателя. На `/connections` (demo) — Telegram-вход и «Агент действует по вашему поручению»: presets «Только сохранять» / «Помощник» / «Помощник с поручениями», колонки «Сам / С подтверждением / Никогда», четыре сценария (приглашение и снимок для всех, ссылка другу, библиотека команды, работа с меткой «Личное»), запрос подтверждения с «Разрешить один раз» и «Разрешить и дальше…», журнал и «Остановить всех агентов»; минимальное ревью и корпоративная граница. Это прототип UX на моках; `import.preview/commit`, MCP capture, поручения и review API ещё не подключены к серверу. [Ревизия интерфейса](../../reviews/2026-09-14-opus-ux-implementation/review.md) · [бренд и словарь](../../reviews/2026-09-14-fable-brand-update/review.md).

## Что будет в первых выпусках

**M1 Light — положить и открыть**
- (plan) MCP capture из агента и загрузка ZIP/интерактивного HTML (real сейчас: файл и статический HTML); «Входящие от агента» с происхождением.
- Режимы агента «Только сохранять» и «Помощник»: безопасное агент делает сам, ссылку открывает после вашего подтверждения; журнал действий агента и «Остановить всех агентов».
- Моя Полка: работы, минимальные папки, версии; принятый просмотр HTML в изоляции.
- По умолчанию — только владелец. «По ссылке» — явным действием, без каталога и с запретом индексации, который не заменяет контроль доступа.
- Чувствительные работы (здоровье, расписание) помечаются «Личное» и требуют предупреждения перед внешним доступом.
- Редакционная витрина демонстрационных работ без входа.

**M1.1 Discovery — показать всем и взять за основу**
- «Показать всем»: отдельный неизменяемый снимок, редактирование публичного описания, модерация, снятие и жалобы.
- Сохранение, одна реакция «Полезно», «Взять за основу» с указанием автора и передачей своему агенту.
- Агент готовит публикацию сам, подаёт — с вашим подтверждением прав; ограниченные по сроку поручения для ссылок.
- «Мои публикации»: просмотры людей, сохранения, ремиксы — без слежки за читателями.

**M1.3 Team — библиотека команды** в Light; **M4 Enterprise** — внутренняя установка и перенос из Light.

Это целевой объём, а не список реализованных возможностей. Полка не редактирует работы как Figma, не заменяет офисные программы и диск, не делает встроенный чат, подписки и ленту рекомендаций. PPTX можно хранить как файл без обещания конвертации.
