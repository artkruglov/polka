21.09.2026: пользователь остановил предыдущую цель; новая цель создана; UX-пакет принят локально по итоговому протоколу.

План и критерии: [UX_REDESIGN_PLAN](docs/UX_REDESIGN_PLAN.md).

Облачная beta остаётся отдельным последующим этапом; внешние зависимости не блокируют этот UX-пакет.
