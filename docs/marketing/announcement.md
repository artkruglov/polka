# Анонс: рабочее место для ваших агентов

> Черновик для публикации. Факты сверены с [CHANGELOG](../../CHANGELOG.md) и [status.md](../status.md) на 02.10.2026 (версия 0.7.0). Позиционирование — [POSITIONING](../specs/POSITIONING.md).

## Длинная версия (блог, GitHub Release)

### Агенту нужно место, где его работа переживает чат

Вы просите агента сделать отчёт, прототип или разобрать исследование. Чат закончился, и работа осталась в нём: следующий чат начинает с нуля, другой агент её не видит, коллеге нечего открыть.

Полка теперь работает как **рабочее место для ваших агентов**: папка с версиями, ссылка для людей и чтение для других агентов.

### Что это значит на деле

- **Папка, которую агент правит сам.** Работа-проект (набор связанных страниц, документов, картинок) — это папка. Агент по MCP, без выхода в сеть, перечисляет её файлы (`polka_list_files`), читает нужный (`polka_read_file`) и сохраняет следующую версию с добавленными, заменёнными и удалёнными файлами (`polka_change_files`). Остальные файлы копирует сервер, поэтому большой проект меняется одним небольшим вызовом. Из терминала то же делают `polka pull` и `push`.
- **Версии, а не перезапись.** Каждое сохранение — неизменная версия. Старую можно открыть и сравнить, ссылку закрыть в один клик.
- **Один диск для любого агента.** Начатое в одном чате продолжает другой чат или другой агент: находит работу по словам внутри, спрашивает «что изменилось с прошлого раза», читает заметку полки «как у нас принято», смотрит снимок полки на дату.
- **Ссылка для людей.** Результат открывается без аккаунта в Claude или ChatGPT.
- **Для своих установок:** полки отделов, сервисные доступы для cron и CI с названным ответственным человеком, короткие токены задач.

### Чем это не является

Это не файловая система и не синхронизируемая папка: нет монтирования, перезаписи на месте и блокировок. Папка для чата — работа-проект (страницу меняют по-прежнему через `polka_revise`); файл читается до 256 КиБ за вызов, хранится до 5 МиБ, проект — до 400 файлов и 48 МБ. Зависимости и промежуточный мусор не хранятся.

### Как попробовать

Подключите агента (`https://polochka.app/mcp`), попросите сохранить исследование как проект, затем в новом чате: «возьми мою работу про X, добавь раздел и сохрани новую версию». Для скриптов — [PUBLISH_API](../PUBLISH_API.md), для деталей — [AGENT_WORKSPACE](../specs/AGENT_WORKSPACE.md). Код открыт (AGPL-3.0): [github.com/artkruglov/polka](https://github.com/artkruglov/polka).

## Короткая версия (Telegram)

Полка теперь рабочее место для ваших агентов.

Работа — это папка с версиями. Агент по MCP, без выхода в сеть, смотрит файлы, читает нужный, добавляет и удаляет файлы и сохраняет следующую версию; остальное копирует сервер. Другой чат или агент продолжает с того же места, находит работу по тексту и видит, что изменилось. Вам — ссылка без аккаунта.

Не диск и не синхронизация: каждое сохранение — новая версия. Код открыт.

polochka.app

## English

**Polka is now a workspace for your AI agents.**

A work is a folder with versions. Over MCP, with no network access, an agent lists its files, reads one, and saves the next version with files added, replaced or removed; the server copies the rest. Another chat or agent picks up where it left off, finds the work by text and sees what changed. You get a link that opens without an account.

Not a disk or a synced folder: every save is a new version. Open source (AGPL-3.0).
