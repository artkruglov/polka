# Бриф: шесть новых рекламных карточек

Формат как у существующих 16 ([../assets/cards](../assets/cards/README.md)): каждый сюжет в 16:9 (1600×900) и 4:5 (1080×1350), знак «п», адрес `polochka.app`. Картинок нет: нужен генератор или дизайнер; тексты согласованы с [POSITIONING](../specs/POSITIONING.md). Не рисовать числовые метрики и логотипы сторонних продуктов.

| № | Сюжет | Заголовок | Подпись | Элементы макета |
|---|---|---|---|---|
| 09 | Папка для агента | Работа переживает чат | Агент кладёт файлы на Полку и берёт их в следующем чате | Чат слева, папка с файлами справа, стрелка «в следующем чате» |
| 10 | Файлы без сети | Добавить, заменить, удалить | Агент меняет набор файлов по MCP, остальное копирует сервер | Список файлов: один добавлен (+), один заменён, один удалён (−), остальные серые |
| 11 | Версии | Каждое сохранение — версия | Старую можно открыть, ссылку — закрыть | v1, v2, v3 в ряд; у v2 метка «по ссылке» |
| 12 | Другой агент продолжает | Продолжит любой чат | Находит работу по тексту и видит, что изменилось | Два чата-пузыря, общая папка между ними, строка поиска с фрагментом |
| 13 | Ссылка для людей | Откроют без аккаунта | Ссылка на ту же папку, версия не меняется | Ссылка, карточка получателя без поля входа |
| 14 | Своя установка (команды) | Cron и CI с названным ответственным | Сервисный доступ: уходит человек — доступ замораживается | Схема: бот → полка, подпись «отвечает: Анна», замок; пометка «на своей установке» |

Тон: как в имеющихся карточках (коротко, без восклицаний). Не использовать слово «диск» без «с версиями».
