# Прототип интерфейса Полки

[Открыть полку](polka-interface.html). Самодостаточный HTML-файл: можно открыть в браузере без сборки и установки зависимостей. Прототип не обращается к внешним ресурсам.

Проверяемый путь: полка → папка → работа → «Поделиться» → вид получателя → версии → явное обновление по ссылке. Доступны поиск, избранное, демонстрация новой работы, приглашённой аудитории и отключённой ссылки. «Начать заново» возвращает исходные примеры.

Все данные вымышлены и хранятся только в памяти вкладки. Вставленный HTML не выполняется; файлы не загружаются, письма не отправляются. Адрес `polka.example` — пример, не опубликованная работа. Настройки доступа, срока и действий показывают будущий сценарий, но не реализуют серверную защиту. После перезагрузки изменения сбрасываются.

Проверено в браузере 13 сентября 2026: основные переходы, поиск, версии, отключение ссылки, возврат фокуса после Escape; ширины 320, 390, 768 и 1280 CSS px. [Запись проверки](evidence/checks.json) содержит область проверки и снимки. Это не пользовательское исследование и не приёмка безопасности S01–S12.

Следующий шаг — перенести принятые сценарии в приложение и связать их с реальными аккаунтами, хранилищем и проверкой прав из [дорожной карты](../DELIVERY_PLAN.md). Будущие элементы не появляются в рабочем интерфейсе до соответствующей приёмки.
