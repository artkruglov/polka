# Прототип интерфейса Полки · v2

Это интерактивный дизайн-макет. Для открытия нужен локальный HTTP-сервер: JavaScript-модули не рассчитаны на двойной щелчок по файлу.

Из корня репозитория:

```sh
python3 -m http.server 4388 --bind 127.0.0.1 --directory docs/design
```

Откройте [Полку на этом компьютере](http://127.0.0.1:4388/polka-interface.html). Зависимостей npm и сборки макета нет. Не запускайте второй сервер, если этот адрес уже работает.

## Что можно попробовать

- Поиск, сортировка, карточки/список, папки, недавние и избранное.
- Отчёт, интерактивный пример сервиса, три слайда и страницы. У прототипа можно переключать период и отмечать задачи.
- Новую демонстрационную версию, историю, просмотр получателя и явное обновление прежней ссылки.
- Открытие/отзыв доступа и повторное создание адреса. Настройки не включают отключённую ссылку обратно.
- «Сценарии»: пустая полка и будущий доступ приглашённым. На телефоне разделы доступны через меню.

Всё вымышлено и хранится только в памяти вкладки. HTML не выполняется, файлы и письма не отправляются. Адрес `polka.example` — пример. Срок, права, вход и ограничения скачивания не реализуют серверную защиту. Перезагрузка и «Сбросить» возвращают начальное состояние.

## Структура

`polka-interface.html` подключает локальные файлы `ui/`: токены, стили, модель, общие элементы, примеры и приложение. `model.test.mjs` проверяет важные переходы, включая обнаруженные ревью ошибки. Это не проверка серверной авторизации.

```sh
node --test docs/design/ui/model.test.mjs
```

Скриншоты и браузерная запись новой проверки: [review-v2](review-v2/checks.json). Старый каталог `evidence/` — историческая проверка первого макета с собственным hash, не эталоны текущего кода. В v1 часть desktop-снимков имела несовпадение масштаба/viewport; новые снимки записывают фактические размеры и DPR.
