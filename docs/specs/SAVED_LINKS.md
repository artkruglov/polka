# «Сохранить как ссылку»

> **Статус:** реализовано 24.09.2026. Работает независимо от `URL_IMPORT_ENABLED`, миграции не требует. С 25.09.2026 веб-интерфейс не предлагает «Сохранить как ссылку» (карточка ссылки и экран ошибки импорта убраны, см. [URL_IMPORT_SUPPORT](URL_IMPORT_SUPPORT.md)); остаются MCP `polka_save_link` и `POST /api/links`, а сохранённые закладки по-прежнему показываются на полке и у получателя.

Ссылку можно сохранить как есть, как закладку. Это нужно для того, что Полка не может или не имеет права скопировать: артефакты Claude, страницы за проверкой на бота, неудавшийся импорт. Работа хранит адрес, название и заметку. Содержимое остаётся у сервиса.

## Где предлагается

- В карточке ссылки AI-сервиса на странице «Сохранить» ([URL_IMPORT_SUPPORT](URL_IMPORT_SUPPORT.md#таблица-источников)), вторым способом после агента.
- На экране ошибки импорта: `source_blocked`, `robots_disallowed`, `robots_unavailable`, `timeout`, `source_unavailable`, `not_allowed`, `provider_adapter_required`, `renderer_*` и других.
- Агенту — инструмент MCP `polka_save_link {key, url, title?, note?, folderId?}` (scope `capture`). Скилл и `llms.txt` советуют его, когда пользователь не может дать код.
- HTTP: `POST /api/links` с теми же полями, для браузера владельца.

## Что хранится

Одна версия типа `single` с mime `application/vnd.polka.link+json` (`LINK_MIME`) и файлом `{"v":1,"url":…,"note":…}` до 8 КБ. Имя файла `<host>.link.json`: по нему полка показывает хост и сервис, не читая файл. Сервис, значок и название по умолчанию («Артефакт Claude», «Чат ChatGPT» или хост) берутся из таблицы провайдеров [packages/contracts/link-providers.ts](../../packages/contracts/link-providers.ts). Адрес — только http(s), без логина и пароля, до 2048 символов.

Сохранение идёт обычным путём одиночной загрузки (`beginUpload` → `uploadBytes` → `finalizeUpload` в одной транзакции). Поэтому квота, идемпотентность по `key`, журнал, аналитика `work_saved` и корзина работают как для любой работы. Отдельной таблицы и миграции нет.

Сервер не открывает ссылку AI-сервиса ни для чего, даже ради названия (Claude, ChatGPT, Gemini, v0, Perplexity, AI Studio, Gist). Для обычных сайтов и SPA-хостов, если владелец не дал название и импорт по ссылке включён, сервер один раз читает `<title>`/`og:title` через `fetchPublic` как PolkaRenderer, после проверки robots.txt. og:image не сохраняется.

## Показ

- **Полка:** обложка со значком сервиса, названием и хостом. «Открыть ↗» ведёт на оригинал в новой вкладке через `GET /api/revisions/:id/open`: это 303, только для владельца, с `Referrer-Policy: no-referrer`.
- **Страница работы:** та же карточка вместо просмотра, заметка и подсказка «Содержимое хранится у сервиса. Чтобы сохранить копию, используйте расширение или попросите агента».
- **Получатель ссылки:** карточка с кнопкой прямо на оригинал (`rel="noopener noreferrer nofollow"`). Файл он получает через `/api/view/bytes` по grant, как текст.
- **Перед отправкой** владелец видит в окне «Поделиться», что у получателя должен быть доступ к оригиналу. Для Claude: «Получатель откроет артефакт Claude, если автор включил доступ по ссылке».

## Безопасность и модерация

Фильтр содержимого читает название, адрес и заметку ([CONTENT_FILTER](CONTENT_FILTER.md)). Домены из `content-filter/lists/domains.txt` (пиратство, казино, логгеры IP вроде iplogger.org) ловятся по адресу, категории — по тексту. Решение при выпуске ссылки такое же, как для любой работы: блокировка, ожидание проверки, стоп-лист по SHA-256. Проверено в `tests/saved-links.test.ts`.
