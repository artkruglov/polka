# Продукт

> **Статус:** контракт. Продуктовые границы и словарь; текущие возможности — [status.md](../status.md).

Полка сохраняет артефакты из AI-агентов как независимые страницы, которыми удобно делиться. Получателю не нужен аккаунт исходного сервиса. Автор возвращается к своим материалам и версиям; читатель открывает отчёты, калькуляторы, планы и прототипы прямо в браузере.

Первая фраза: **«Сделали с агентом. Покажите другим.»** Практическая польза: сохранить результат вне чата и отправить работающую ссылку. «Без VPN» — желаемый результат для целевых пользователей, проверяемый на реальном домене и устройствах; не основание обещать доступность во всех сетях. Размещение в РФ — выбранное направление hosted-поставки, пока не завершённое размещение.

## Кому и зачем

| Человек | Ситуация | Результат | Основной путь |
|---|---|---|---|
| Автор с Claude/Codex/другим агентом | Сделал полезную страницу, хочет показать | Агент сохраняет и возвращает ссылку | MCP → immutable revision → viewer → ссылка |
| Автор без настройки MCP | Уже есть публичная ссылка или HTML-файл | Независимая копия без ручного копирования кода | Поддержанная ссылка → импорт; файл как fallback |
| Друг/коллега | Исходный сервис не открывается или просит вход | Сразу открыть содержимое и воспользоваться | Ссылка Полки → live viewer без исходного аккаунта |
| Постоянный автор | Материал потерялся среди чатов | Найти, открыть, обновить, отозвать ссылку | Личная полка → поиск/папка → версии |
| Любопытный читатель | Хочет интересный отчёт или инструмент | Найти, открыть, сохранить интересное | Темы → артефакт → закладка/похожее |
| Команда | Несколько сотрудников создают результаты агентами | Общая библиотека с управляемым доступом | Следующий этап: membership, общий workspace |
| Компания | Данные и агенты должны работать внутри | Установить то же ядро в своей инфраструктуре | Open-source base → enterprise policies позднее |

## Scope первого выпуска

Регистрация без администратора, первая личная полка, MCP минимум для двух проверенных клиентов, самостоятельный HTML и ограниченный bundle, живой изолированный просмотр, независимые версии, приватное хранение и отзываемые ссылки. Исследовать и реализовать импорт хотя бы одного поддержанного публичного источника; не убирать эту главную гипотезу за словом best-effort. Если импорт не проходит приёмку, beta получает честный scope MCP/файла и другое описание первого CTA; это фиксируем отдельным решением.

Редакционный каталог 12–20 законченных примеров поддерживает вход и возвращения. Пользовательская публикация, реальные реакции и модерация — отдельный этап public community после проверки основной beta. Вымышленные авторы не считаются пользователями.

## Не в MVP

Встроенная модель/чат, зеркалирование чата, PPTX-редактор, совместный Figma-редактор, произвольные серверные приложения, выполнение npm-проектов посетителей, Telegram-бот до основного capture, сложный рекомендательный алгоритм, платежи, SSO и корпоративные approvals. Эти jobs не удалены из видения, но не блокируют первый полезный цикл.

## Словарь

«Артефакт» допустим в позиционировании для аудитории AI-агентов. На конкретной карточке — «отчёт», «калькулятор», «план», «страница». «Работа» не универсальное название всего. «Только я», «По ссылке» и «Опубликовано» различаются. Unlisted не называется «доступ только другу»: любой получатель ссылки может переслать её. «Агент подключён» только после реального запроса; не после копирования конфигурации.

## Метрики и проверка гипотез

Главное событие — независимый получатель открыл сохранённый артефакт и выполнил его ключевое действие. Меряем воронку visit → start → authenticated → capture receipt → share → recipient open, time-to-first-value, ошибки по источникам, возвращение автора за вторым сохранением, reader/author D7. Не пишем токены, содержимое и полный URL в аналитику.

Предлагаемый допуск к расширению beta: 8 из 10 новых авторов сохраняют без помощи; 8 из 10 получателей открывают и выполняют задачу; 3 из 10 авторов возвращаются за вторым сохранением за неделю. Это пороги будущего эксперимента, не полученные результаты и не прогноз 50 000 пользователей.
