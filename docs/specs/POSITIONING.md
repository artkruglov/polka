> **Статус:** с 02.10.2026, вместо «Полка хранит принятое» (01.10.2026, отменено: непонятно и не отражало идею Drives). Решение — [DECISIONS](DECISIONS.md#02102026-полка--рабочее-место-агента-с-версиями), состав — [AGENT_WORKSPACE](AGENT_WORKSPACE.md). Контракт [PRODUCT.md](PRODUCT.md) не меняется. Что работает у пользователя сейчас — [status.md](../status.md).

## Одной строкой

**Полка — рабочее место для ваших AI-агентов: папка с версиями, ссылкой для людей и чтением для других агентов.**

## Зачем

Облачный агент теряет работу между чатами и не может передать её другому агенту или человеку. У Vercel Sandbox Drives это решает диск внутри песочницы. У Полки то же, но с версиями и ссылкой: агент кладёт в работу-папку файлы, в следующем чате перечисляет их, читает нужный, добавляет и удаляет файлы и сохраняет следующую версию; другой агент находит работу по тексту и видит, что изменилось; человек открывает результат по ссылке без аккаунта.

## Три тезиса

1. **Папка, которая переживает чат.** Работа-проект — набор связанных файлов. Агент работает с ней по MCP без выхода в сеть (`polka_list_files`, `polka_read_file`, `polka_change_files`) или из терминала (`polka pull/push`). Каждое сохранение — неизменная версия: старую можно открыть и сравнить.
2. **Один диск для любого агента.** Начатое в одном чате продолжает другой чат или другой агент: поиск по тексту, список изменений с прошлого раза, заметка полки «как у нас принято», снимок полки на дату.
3. **Ссылка для людей.** Результат открывается без аккаунта в Claude или ChatGPT. Версия неизменна, ссылку можно закрыть. Отметка «принято» (одна отметка владельца или куратора) показывает агентам и коллегам, какая версия настоящая.

## Что говорить, а что нет

Говорим только то, что работает у адресата сегодня.

- **На polochka.app:** личные полки; работа-проект как папка (`polka_capture` с манифестом `project-v1`, CLI, `polka pull/push`) и три операции с файлами по MCP и HTTP; версии; поиск с ранжированием; `GET /works`, лента, снимок; карточка полки; отметка «принято» (видят вы и ваши агенты; получатель ссылки её не видит); ссылка для людей.
- **Только на своей установке (флаги `TEAM_SHELVES=on`, `SERVICE_ACCOUNTS=on`):** полки отделов, поиск по нескольким полкам, сервисные доступы и токены задач, режим ссылки `pinned/follows` (действует только на сервисные доступы).
- **Честные границы:** это не файловая система и не синхронизируемая папка: нет монтирования, перезаписи на месте и блокировок; каждое сохранение — новая версия. Папка для чата — только работа-проект (не одна страница); файл до 256 КиБ читается за вызов, до 5 МиБ хранится, проект до 400 файлов и 48 МБ. Зависимости и промежуточный мусор не храним.
- **Не говорим:** что агент «не двигает ссылку» вообще (так ведёт себя только сервисный доступ); вебхуки (нет); агент не принимает версии (отметку ставит человек); сравнения с другими продуктами и рыночные числа без проверки.
- **О Vercel Sandbox Drives** публично не пишем: сведения из документации и агрегаторов, из чистого браузера не проверены ([AGENT_ACCESS_AND_MEMORY](AGENT_ACCESS_AND_MEMORY.md#открытое-и-непроверенное)). Внутренне: у них диск внутри песочницы, у нас рабочее место с версиями и ссылкой для людей.

## Формулировки

- Главная: eyebrow «Рабочее место для ваших агентов», заголовок «Сделали с агентом. Покажите другим.» остаётся входом (контракт PRODUCT.md), подзаголовок — про папку, версии и ссылку.
- Одна фраза (GitHub About, соцсети): «Рабочее место для ваших AI-агентов: папка с версиями, ссылка без аккаунта для людей, поиск и чтение для других агентов.»
- Описание плагина: «Работайте с агентом в папке на Полке: файлы, версии, ссылка для людей; другие чаты находят и продолжают работу.»
- English: «A workspace for your AI agents: a folder with versions, a link anyone can open without an account, and search and read access for other agents.»

## Как проверить

Сначала пороги из PRODUCT.md. Дополнительно (`npm run metrics:agent-access`): доля чтений агентов к открытиям ссылок за 30 дней, число токенов агентов; сколько работ-проектов правится больше одного раза. Позиция подтверждена, если авторы возвращаются к той же работе-папке за второй версией, а не только сохраняют и делятся.

## Риски

- Рамка «диск» обещает больше, чем даёт версионное хранилище. Всегда добавлять «с версиями» и не обещать монтирование.
- Папка для чата работает только для работы-проекта: страницу (одиночный HTML) меняют через `polka_revise`. Сообщение «работа — это папка» должно вести к проекту.
- Спрос на агентов без человека не подтверждён (ноль запросов): сервисные доступы подаём как возможность своей установки.
