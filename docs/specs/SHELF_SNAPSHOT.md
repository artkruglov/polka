# Снимок полки на дату

> **Статус:** в коде с 02.10.2026 (`GET /api/v1/snapshot`, версия 0.6.0). Экрана и MCP-инструмента нет.

## Зачем

Ответить «что лежало на полке на такой-то день и какая версия была принята»: для сверки с тем, что ушло заказчику, для отчёта за период и для агента, который собирает дайджест «как было». Версии неизменны, поэтому ответ о прошлом моменте (старше минуты) не меняется.

## Что отдаёт

`GET /api/v1/snapshot?at=<ISO 8601 с поясом>&limit=&cursor=` (право `read`, полка токена, ограничение папками действует):

- работы, которые существовали и не были в корзине на момент `at` (убраны в корзину позже — входят; были в корзине тогда — нет, даже если потом вернули; удалённые навсегда — нет);
- у каждой: версия, бывшая последней на тот момент (`revision`: номер, размер, дата), и версия, принятая на тот момент (`acceptedRevisionId`);
- порядок и курсор по id работы, `limit` 1–100.

Момент в будущем — `400`. Байтов и секретов ссылок нет.

## Чего не умеет (и почему)

- **Название и папка текущие,** не на тот момент: они не версионируются.
- **Корзина и принятие читаются из журнала действий** (`audit_outbox`: `artifact.trashed`, `artifact.restored`, `revision.accepted`). Работа, которую убрали в корзину и вернули, на дату внутри этого промежутка не показывается. Если журнала по работе нет (строки до его полного ведения), берётся нынешнее время помещения в корзину. `acceptedRevisionId: null` значит «на тот момент не принята» (в том числе отметку сняли): отметки и их журнал появились вместе в 0.5.0.
- **Свежий момент (последняя минута) может ещё измениться:** долгое сохранение получает время начала, а видно становится после завершения. Для отчётов берите момент хотя бы минуту назад.
- В адресе знак `+` пояса кодируйте как `%2B` или пишите `Z`; пробел перед `HH:MM` в конце сервер понимает как `+`.
- Содержимое версий не отдаётся: нужную читают через `polka_read_source` по `revision.id`.

## Как устроено

Один запрос: для каждой работы последняя версия с `created_at <= at`, последнее перемещение в корзину или из неё и последняя отметка принятия до `at` (боковые соединения; частичные индексы по журналу — миграция 063). Граница включительная. Чтение считается в `agent_read_days`. Тест: `tests/agent-management.test.ts` («the shelf snapshot…»).
