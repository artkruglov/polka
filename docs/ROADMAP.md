# Единственная дорожная карта

## 22.09.2026 — «Ссылка на артефакт → показано на Полке»

Hosted pilot работает на https://polochka.app (статический HTML, MCP, ссылки, отзыв). Сервер Полки не может сам забрать артефакт по ссылке Claude/ChatGPT: ссылки нового Share-диалога Claude открываются только вошедшему пользователю, сайт закрыт Cloudflare (HTTP 403 «Just a moment…» на запрос без браузера), а данные публичных артефактов отдаёт внутренний API (HTTP 403, см. research/CLAUDE_IMPORT_EXPERIMENT.md). Обход защиты и чужие cookies исключены. Автоматический перенос возможен только двумя легитимными путями — Claude сам передаёт код (коннектор) или браузер пользователя с его доступом (расширение).

## Что не должно разрастись

MVP не требует общего approvals engine, Telegram, Figma-редактора, SaaS billing, SSO, Kubernetes, всей соцсети и гарантии 50 000 пользователей. Корпоративные требования сохраняются в C2/C3 и не смешиваются с B1. Вместе с тем MVP не может закончиться красивой библиотекой без настоящего capture и live viewer.

## Режим выполнения

Завершать этап только с доказательствами. При блокере (доступ к SMTP, облаку, тестовому клиенту) фиксировать его и выполнять независимые задачи. Любое изменение scope отражать в DECISIONS и критериях; архив не переписывать как будто старое решение всегда было новым. Оценка сроков после B2-spike; не выдаём календарную дату релиза при неизвестной совместимости импорта.

B1 evidence: [рабочий срез onboarding](reviews/2026-09-20-onboarding/REVIEW.md). Экраны и локальный email flow готовы; SMTP/user-приёмка остаётся.

B2 evidence: [ревизия и корпус](reviews/2026-09-20-requirements-revision/REVIEW.md). Следующий шаг — отрицательные fixtures и изолированный viewer spike; отдельно внешний corpus для URL adapter.

Исполнение задач моделями: [MODEL_WORKFLOW](MODEL_WORKFLOW.md). Astra — архитектура/приёмка; Luna — ограниченные изменения; Sol — сложная интеграция. Это не меняет scope и критерии этапов.

Текущий B2: single-HTML manifest сохранён в revision/receipt, локальный viewer частично проверен. Следующая реализация — multi-file capture по [BUNDLE_SPEC](BUNDLE_SPEC.md). [Последние доказательства](reviews/2026-09-20-manifest-runtime/REVIEW.md). Это уточняет следующие шаги из ранних evidence, не закрывает B2.
