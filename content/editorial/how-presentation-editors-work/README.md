# Как устроен редактор презентаций изнутри

- **author:** Редакция Полки
- **license:** Apache-2.0
- **topic:** Исследования
- **task:** Понять, из каких слоёв состоит редактор презентаций и почему экспорт в PowerPoint так часто ломает графики.
- **action:** Нажимать на слои схемы «документ → шаблон → отрисовка → экспорт» и читать, что в каждом хранится и где он ломается; сравнить результаты живой проверки двух открытых проектов.
- **expected:** Четыре слоя, аргументы против canvas-only, список «что не хранить как главную версию», таблица проверки CreatPPT и Presenton, таблица открытых проектов с лицензиями, чек-лист перед заимствованием кода. Без JavaScript видны все разделы; переключается только панель слоя (первый слой показан по умолчанию, остальные — в noscript).
- **demo:** Автономный оригинальный HTML с локальными CSS/JavaScript.

## Источники


- Открытые проекты CreatPPT и Presenton, их репозитории и лицензии; живая проверка экспорта (сентябрь 2026).
