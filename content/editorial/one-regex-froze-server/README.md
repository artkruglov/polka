# Одна регулярка, которая могла остановить сервер

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Объяснить, как квадратичное регулярное выражение в классификаторе HTML могло заморозить весь сервер, кто это нашёл и как один проход по дереву это исправил.
- **action:** Двигать ползунок числа тегов и смотреть, как растёт работа регулярки против одного разбора; запускать пошаговую анимацию сканирования; выбирать размер страницы и сравнивать время до и после фикса.
- **expected:** Для N тегов регулярка читает N(N+1)/2 тегов, разбор — N; на 480 КБ измерено 67 с до фикса, на 5 МБ «плоской» страницы после фикса — 85–430 мс; эпилог про вложенные страницы (c1dd044). Таймлайн честно показывает, что rc.3 удвоил цену.
- **demo:** Полностью автономный оригинальный HTML с локальными CSS/JavaScript. Без JavaScript видны формула для N = 12, таблица измерений, таймлайн и код до/после; ползунок, анимация и выбор размера появляются только со скриптами.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Модель «тегов» — учебное упрощение формы роста; настоящие времена приведены отдельно с указанием, что измерено, а что экстраполировано.
