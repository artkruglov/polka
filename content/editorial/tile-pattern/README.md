- **author:** Редакция Полки
- **license:** Apache-2.0
- **source:** original synthetic editorial material; no external assets
- **task:** Понять, как небольшие изменения повторяемого элемента меняют общий ритм узора.
- **action:** Настроить цвета, плотность и seed, затем вернуть исходный вариант.
- **expected:** Применение настроек перерисовывает детерминированный узор; одинаковый seed и reset возвращают тот же результат.
- **demo:** Локальный SVG/JavaScript пример; настройки живут только в открытой странице и не сохраняются.
