# Рюкзак на день

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Собрать и проверить короткий чеклист для однодневной прогулки.
- **action:** Отметить вещи по группам, увидеть прогресс и сбросить отметки.
- **expected:** Читатель отделяет основу от вещей под погоду и маршрут; отметки не сохраняются.
- **demo:** Полностью автономный оригинальный HTML с синтетическим редакционным списком.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Список не является универсальной инструкцией: он предлагает пример вопросов перед прогулкой и не делает выводов о безопасности конкретного маршрута.
