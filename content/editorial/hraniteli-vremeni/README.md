# Золотое кольцо: Хранители времени

- **author:** Редакция Полки
- **license:** Apache-2.0
- **topic:** Обучение
- **task:** Познакомиться с проектом по Золотому кольцу для 3 класса: десять городов, десять «ключей памяти».
- **action:** Посмотреть фильм «Три письма из прошлого» и открыть полную игру по кнопке.
- **demo:** Статичная страница проекта, взятая с Полки владельца (работа «Золотое кольцо — Хранители времени», 30.09.2026). Игра и фильмы находятся на внешнем сайте проекта.

## Источники

- Проект владельца Полки. Изображения созданы ImageGen в Codex; исторические сцены — реконструкции (сказано на самой странице).
- Страница содержит одну внешнюю ссылку (игра проекта) и упоминает Юрия Бычкова (автор названия «Золотое кольцо», 1967) как историческое лицо.
