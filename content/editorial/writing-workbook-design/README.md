# Тетрадь, которую хочется заполнять: как устроить домашнюю практику письма

- **author:** Редакция Полки
- **license:** Apache-2.0
- **topic:** Исследования
- **task:** Собрать домашнюю практику письма для младшеклассника, которую ребёнок не бросит.
- **action:** Выбрать тему (гараж, космос, футбол, животные) и цель (границы предложений, трудное слово, пробелы, заглавные) — получить мини-миссию на три дня; распечатать.
- **expected:** Семь правил тетради, каркас миссии, карточка проверки «ПОНЯТНО? → МОЯ ЦЕЛЬ → ИСПРАВИЛ ИЛИ СПРОСИЛ», карта из 24 клеток, конструктор на 16 сочетаний, советы взрослому. Без JavaScript видна пример-миссия «Гараж».
- **demo:** Автономный оригинальный HTML с локальными CSS/JavaScript; кнопка печати вызывает `window.print()`, ничего не скачивается и не отправляется.

**Статус: черновик, не зарегистрирован** — решение за владельцем.
