# Игра по описанию: что на самом деле умеют ИИ-конструкторы игр

- **author:** Редакция Полки
- **license:** Apache-2.0
- **topic:** Исследования
- **task:** Понять, что выдают сервисы «игра по описанию», кто за что платит и где в этой категории реальная незакрытая задача.
- **action:** Двигать ползунки воронки (аудитория, доля начавших, доля опубликовавших, доля платящих) и смотреть, сколько остаётся платящих.
- **expected:** Лестница зрелости «ассет → сцена → прототип → игра для публикации», карта рынка из шести групп, таблица пяти сервисов, три рыночные цифры с оговорками, план проверки идеи за три недели. По умолчанию воронка 10 000 × 3% × 30% × 5% ≈ 5 платящих.
- **demo:** Автономный оригинальный HTML с локальными CSS/JavaScript. Без JavaScript видны все разделы и воронка со значениями по умолчанию.

Сознательно опущены: Verse8 и Remix (блокчейн/крипто-модель, источники — криптобиржи), упоминания блога сооснователя и рекомендации, адресованные конкретной команде. Roblox упомянут только как пример категории, без ссылок (ресурс ограничен в РФ).
