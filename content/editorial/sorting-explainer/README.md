# Как числа находят порядок

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Объяснить на маленьком наборе, как соседние сравнения сортируют числа.
- **action:** Делать шаг, запускать/останавливать автоматическое продвижение и сбрасывать пример.
- **expected:** Ряд `7, 3, 5, 2, 6` приходит к `2, 3, 5, 6, 7`, а подпись объясняет каждое сравнение.
- **demo:** Полностью автономный оригинальный HTML с локальными CSS/JavaScript и синтетическими числами.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Это визуальная модель алгоритма, а не заявление о производительности для больших наборов данных.
