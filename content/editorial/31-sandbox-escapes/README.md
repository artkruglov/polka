# 31 попытка выбраться из песочницы

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Показать, как один ИИ-агент проверял код другого, пытаясь через сборщик страниц прочитать файлы сервера, какие три слоя это держат, и какую дыру (WebRTC) нашла живая проверка просмотрщика на следующий день.
- **action:** Фильтровать 25 приёмов по категории (пути, протоколы и CDN, CSS, динамические импорты, require) и по слою, который их остановил; читать таблицу каналов выхода до и после исправления.
- **expected:** 31 попытка отклонена, 0 утечек; в повторном прогоне 23 приёма остановлены слоями 1–2, два собрались без единого чтения с диска; WebRTC закрыт guard-скриптом при отдаче.
- **demo:** Полностью автономный оригинальный HTML с локальными CSS/JavaScript. Без JavaScript видны все 25 карточек, слои и таблица; кнопки фильтра появляются только со скриптами.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Фрагменты кода на карточках — приёмы из отчёта ревью, сокращённые; хостов CDN и STUN-серверов в тексте нет.

## Источники

- Коммит `8001de3` («fix: runtime builder never reads server files and bounds esbuild memory») — статические строки в `import()`/`require()` (esbuild + acorn), ограда по allow-list библиотек через `realpath`, `user:`-модули только из сгенерированной точки входа, минимальное окружение воркера, ошибки без путей сервера, лимиты 32 файла / 2 МиБ, одна runtime-сборка за раз, `RLIMIT_DATA` 512 МБ на Linux.
- Коммит `be65650` («fix: close require and sloppy-mode bypasses in the runtime import check») — любое упоминание `require` только как прямой вызов с одной строкой, разбор как модуль или скрипт, отказ при невозможности разобрать.
- `apps/server/runtime-guards.ts` (`staticImportsOnly`, `allowedPackageDirs`, `isAllowedLibraryFile`), `apps/server/react-runtime.ts` (`onResolve`/`onLoad`-ограда, повторная проверка `metafile.inputs`), `packages/contracts/runtime.ts` (10 библиотек), `tests/react-runtime.test.ts`.
- Коммит `040be10` («fix(security): pages in the interactive viewer cannot use WebRTC») и `docs/reviews/2026-09-23-viewer-egress/README.md` — таблица каналов до/после, Chrome 153, `webrtc 'block'` игнорируется, `VIEWER_GUARD` (12 конструкторов RTC), позиция guard-скрипта, `X-DNS-Prefetch-Control: off`, список непроверенного (Firefox/Safari, независимый счётчик, DNS).
- `CHANGELOG.md` — rc.2 («Runtime-сборщик не читает файлы сервера…», перечень библиотек и Tailwind v4), Unreleased («…больше не может выйти в сеть через WebRTC»).
- Вне репозитория, рабочая сессия Claude Code 22.09.2026: отчёт ревью рантайма (критическая находка: `import()`/`require()` с шаблонной строкой → маска по диску от корня сборки, `with {type:"text"}`; воспроизведено на подставных файлах), отчёт исполнителя (утечка пути `node_modules` воспроизведена перед фиксом; 10 библиотек → 86 каталогов; второй слой отказывал при выключенном первом), отчёт ревью безопасности (31 попытка через настоящий `buildDerivative` + esbuild, все отклонены, перечень 25 приёмов, «три слоя держат независимо», примечание про `module.require` с простой строкой).
- Повторный прогон Редакции 23.09.2026 на текущем коде: 25 приёмов из отчёта через `buildDerivative`; 23 отклонены (причины отказа на карточках), `module.require(...)` и `new URL(..., import.meta.url)` собрались как обычный код без чтения файлов (в сборке нет путей и содержимого); `allowedPackageDirs` для 10 библиотек — 86 каталогов.
