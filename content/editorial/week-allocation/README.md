# Куда уходит неделя

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Собрать реалистичное распределение недели на 168 часов.
- **action:** Изменить часы, увидеть диаграмму и проверить сумму с ограничениями сна и длительности занятия.
- **expected:** Читатель получает сходящийся недельный план или понимает, какую строку нужно пересмотреть; значения не сохраняются.
- **demo:** Полностью автономный оригинальный HTML с синтетическим примером и локальным CSS/JavaScript.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Диапазон сна 49–70 часов — условие этого учебного примера, а не медицинская или трудовая рекомендация. Проверка по умолчанию: 56 + 40 + 21 + 7 + 14 + 7 + 23 = 168 часов; при изменении поля диаграмма и легенда пересчитываются в текущей вкладке.
