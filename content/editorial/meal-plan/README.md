# Неделя на столе

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Организовать идеи блюд по дням без обещаний о питательной ценности.
- **action:** Заполнить, изменить или очистить поля обеда и ужина.
- **expected:** Читатель получает личный черновик недели и видит прогресс заполнения; данные не сохраняются.
- **demo:** Автономный оригинальный HTML с синтетическим шаблоном.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Это список организации, а не медицинская, диетическая или закупочная рекомендация.
