# Среднее не всегда рассказывает всё

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Показать на синтетическом наборе разницу между средним и медианой.
- **action:** Переключить три шага урока и изменить значение редкой задержки ползунком.
- **expected:** Читатель видит расчёты `6` и `3` для набора `2, 3, 3, 4, 18`, понимает влияние выброса и проверяет пересчёт.
- **demo:** Полностью автономный оригинальный HTML с локальным CSS/JavaScript и вымышленными числами.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Это учебное объяснение, не исследование транспортных задержек. При изменении выброса `x` приложение считает `(2 + 3 + 3 + 4 + x) / 5`, а медиана остаётся третьим элементом упорядоченного списка при заданном диапазоне `5–30`.
