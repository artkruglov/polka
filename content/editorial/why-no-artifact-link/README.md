# Почему сервер не может забрать артефакт по ссылке

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Показать, что на самом деле видит сервер, когда идёт по ссылке на артефакт Claude, и какой путь работает вместо этого.
- **action:** Переключать два пути («Сервер идёт по ссылке» / «Claude приносит код сам»), листать шаги вперёд-назад или показать все сразу.
- **expected:** Путь сервера заканчивается на 403 и пустой оболочке без содержимого артефакта; путь коннектора — ссылкой на Полке без единого запроса к Claude. Обход защиты назван неприемлемым.
- **demo:** Полностью автономный оригинальный HTML с локальными CSS/JavaScript. Без JavaScript оба пути видны целиком как нумерованные списки.

Материал не использует React, CDN, внешние изображения, сеть, storage, аккаунты или данные пользователей. Все числа и коды ответов — из собственного эксперимента Полки 20–21.09.2026; страница не является заявлением о текущем состоянии сервисов Anthropic или OpenAI.
