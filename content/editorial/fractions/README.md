# Дроби на тарелке

- **author:** Редакция Полки
- **license:** Apache-2.0
- **task:** Учебная практика чтения простых дробей на пяти коротких задачах.
- **action:** Выбрать вариант, прочитать объяснение, перейти к следующей задаче и завершить урок.
- **expected:** Ученик различает целое и равные части, читает числитель/знаменатель и получает итоговый результат.
- **demo:** Полностью автономный HTML; все примеры, тексты и иллюстрация синтетические. Данные не сохраняются.

Файл не использует React, CDN, внешние изображения, сеть, storage или данные пользователей. Кнопки доступны с клавиатуры; анимации отключаются через `prefers-reduced-motion`.

Примечание редакции: исправленная формулировка сохранена через MCP как версия 2 и проверена в локальном браузере; экспорт побайтно совпал с index.html. Протокол: ../../../docs/reviews/2026-09-21-editorial-runtime/README.md. Публикация в каталоге и hosted-проверка ещё не выполнены.
