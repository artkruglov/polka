# Матрица выбора выходного дня

- **author:** Редакция Полки
- **license:** Apache-2.0
- **source:** original synthetic editorial material; no external assets
- **task:** Прозрачно сравнить несколько спокойных занятий по собственным критериям.
- **action:** Изменить веса критериев и оценки вариантов, увидеть расчёт и сбросить пример.
- **expected:** Итог равен сумме `вес × оценка` по каждому критерию; изменение поля обновляет таблицу, reset возвращает исходные значения.
- **demo:** Это способ оформить личные предпочтения, а не авторитетная рекомендация; данные живут только в открытой странице.
