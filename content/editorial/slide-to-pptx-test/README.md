# Что происходит с графиком, когда слайд уходит в PowerPoint

- **author:** Редакция Полки
- **license:** Apache-2.0
- **topic:** Исследования
- **task:** Понять, почему экспорт презентации в PPTX прячет или ломает графики и как проверять экспорт.
- **action:** Переключать три схематичные версии одного слайда (браузер, PPTX из редактора, PPTX из конвертера), читать разбор содержимого файлов и причин.
- **expected:** Сценарий из 7 шагов, таблица объектов OOXML (CreatPPT: 1 нативная диаграмма с данными 20/30/40, закрыта белой подложкой, заголовок Arial; Presenton: 0 диаграмм, столбцы фигурами, Georgia), три причины (порядок слоёв, строка в числовое поле, отсутствие семантики в HTML), четыре критерия экспорта, открытый вопрос про PowerPoint. Без JavaScript — текстовая сводка вместо схем.
- **demo:** Автономный оригинальный HTML с локальными CSS/JavaScript; слайды — схематичные SVG-реконструкции, не снимки.

**Статус: черновик, не зарегистрирован** — решение за владельцем. Для статичного снимка нужен `prepare`, снимающий класс `js` (тогда видны все три схемы).
