# Полка

**Сохраните работу, созданную с ИИ, и поделитесь ссылкой, которую удобно открыть.**

Полка задумана как место, куда агент складывает созданные артефакты: HTML-презентации, отчёты, прототипы и файлы. Скажите подключённому агенту «положи на Полку» или вставьте ссылку на поддержанный расшаренный артефакт — результат получит устойчивое хранение, просмотр, версии и удобную ссылку. Ручная загрузка остаётся запасным путём. Компания сможет установить Полку внутри и подключать разрешённых ею агентов.

**Состояние: первый рабочий локальный срез.** Есть React-интерфейс, отдельные аккаунты, PostgreSQL/S3, загрузка изображений и текста, папки, версии и реальные отзываемые ссылки. HTML-viewer, агент, публичный сервис и корпоративная поставка ещё впереди. Прежний релиз Lanka не является релизом Полки.

**[Запустить локально](docs/LOCAL_DEVELOPMENT.md)** · [Что проверено и что дальше](docs/LIVE_SLICE_2026-09-13.md). Рабочая сборка открывается на `http://127.0.0.1:4390`, публичная витрина демо — на `/discover`, исследовательский макет на 4388 остаётся отдельно.

Интерфейсный срез agent-first входа доступен на `http://127.0.0.1:4390/bring`: ссылка или код → проверка → приватная копия → экран получателя. В нём есть честные ветки для закрытого источника и страницы, собираемой JavaScript. Это прототип UX на моках; `import.preview/commit` и MCP capture ещё не подключены к серверу.

## Что будет в первом выпуске

- Загрузка поддержанных файлов с понятным прогрессом, повтором и сохранением оригинала.
- Личная полка и необязательные папки, поиск, версии и возврат к работе.
- Постоянная короткая ссылка, понятная аудитория, отзыв и отдельное разрешение копирования.
- По умолчанию — доступ только владельцу. Работы «По ссылке» не добавляются в каталог; поисковикам передаётся запрет индексации, который не заменяет контроль доступа. Индексируемая публикация появится отдельным явным режимом.
- Публичная витрина шести демонстрационных артефактов открывается без входа; пользовательская публикация через модерацию и интерактивный HTML-runtime ещё впереди.
- Быстрый просмотр документов и известного HTML-примера; интерактивный чужой код — только в подходящей изоляции.
- Следующим срезом — `artifact.capture` через MCP и импорт поддержанной ссылки с сохранением private snapshot; Полка не запрашивает чужие cookies и не делает произвольный URL-прокси.
- Следующим срезом — красивый отчёт из примера без обязательного агента и разрешённая копия.

Это целевой объём, а не список реализованных возможностей. Браузерная папка не означает синхронизацию диска компьютера; PPTX можно будет хранить как файл без обещания универсальной конвертации в редактируемый HTML.
