# Полка

**Сохраните работу, созданную с ИИ, и поделитесь ссылкой, которую удобно открыть.**

Полка задумана как место для HTML-презентаций, отчётов, прототипов и файлов: свои папки, быстрый просмотр, версии и совместная работа. Можно принести результат любого агента или начать с красивого примера. Компания сможет установить Полку внутри и подключать разрешённых ею агентов.

**Состояние: новый проект, подготовка реализации.** Репозиторий содержит отобранные требования, архитектуру и план; работающего приложения, публичного сервиса и команды установки пока нет. Прежний релиз Lanka не является релизом Полки.

## Что будет в первом выпуске

- Загрузка поддержанных файлов с понятным прогрессом, повтором и сохранением оригинала.
- Личная полка и необязательные папки, поиск, версии и возврат к работе.
- Постоянная короткая ссылка, понятная аудитория, отзыв и отдельное разрешение копирования.
- Быстрый просмотр документов и известного HTML-примера; интерактивный чужой код — только в подходящей изоляции.
- Красивый отчёт из примера без обязательного агента.

Это целевой объём, а не список реализованных возможностей. Браузерная папка не означает синхронизацию диска компьютера; PPTX можно будет хранить как файл без обещания универсальной конвертации в редактируемый HTML.
