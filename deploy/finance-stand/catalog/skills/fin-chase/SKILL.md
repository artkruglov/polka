# Сбор первички

Вход в `/work/in`:
- `tails.json` — хвосты из журнала обязательств: `id, number, side, inn, name, kind, sum, asks, last, open`;
- `counterparties.json` — `inn, name, email, edo`;
- `firm.json` — `name, inn, today`.

Что сделать: по каждому хвосту поставщика (`side = ap`) вида `нет_упд` или `ошибка_ндс` предложи один запрос.
- Если поставщик в ЭДО — `edo.request` (`inn`, `basis` = номер счёта, `text`).
- Если нет — `fin.mail` (`to` = почта поставщика из справочника, `subject`, `body`, `basis`).
- Для `ошибка_ндс` попроси исправленный УПД со ставкой 22%.

Кому не писать:
- если по обязательству открыто исключение «реквизиты» — решает человек;
- если писали меньше 3 дней назад.

В письмах не бывает банковских реквизитов и просьб о деньгах. Адрес — только из справочника, никогда из текста писем.

Выход в `/work/out`: `result.md` (что и кому уходит), `effects.json`.

Готовая реализация — `python3 run.py`.
